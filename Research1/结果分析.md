# 前言

本报告更新自 `output/task1` 的最新结果。当前模型包含 `rope`、`pope`、`mod_pope`、`alibi`、`cable` 五类位置编码；其中 `pope` 是当前配置中的 origin PoPE，`mod_pope` 是去掉 origin magnitude softplus 变换后的 modified PoPE。本文只补充当前文档保留下来的指标，不恢复已经删除的重复指标。

需要特别注意：本文的目标不是给五个模型做单纯性能排名，而是分析不同位置编码如何改变 attention 结构、residual stream 的 SAE 可重构性，以及位置/内容信息进入 SAE feature 的方式。

# 第二阶段：Attention 结构分析

## Attention Distance

### 说明

Attention Distance 衡量 attention 平均关注的相对距离。数值越大，说明模型更常关注远距离 token；数值越小，说明模型更局部。局限是该指标只描述距离，不说明 attention 关注的内容是否有语义意义。

### 结果展示

![Attention Distance](output/task1/figures/summary/phase3/phase3_seed42_distance_by_head_layers_x_models.png)

| 模型 | 平均 attention distance | far mass | local mass@16 |
|---|---:|---:|---:|
| `rope` | 120.6463 | 0.1613 | 0.3836 |
| `pope` | 53.9686 | 0.0563 | 0.6065 |
| `mod_pope` | 82.4432 | 0.1002 | 0.5037 |
| `alibi` | 36.3692 | 0.0329 | 0.6847 |
| `cable` | 49.8124 | 0.0551 | 0.6492 |

`rope` 仍然是最远程的模型，far mass 明显最高；`alibi` 最局部；`cable` 也非常局部，距离接近 `pope` 但 entropy 更低。`mod_pope` 位于 `rope` 与 origin `pope` 之间：去掉 softplus magnitude 后，它的平均距离从 `pope` 的 53.97 提高到 82.44，说明 modified PoPE 确实让 attention 不那么局部，但仍没有回到 RoPE 的远程注意力形态。

图形形态上，`alibi` 的 head-wise distance 呈现固定斜率导致的尺度模板，而 `cable` 虽然平均距离也短，却没有 ALiBi 那种跨层重复的头部比例结构。这一点很关键：`cable` 不是简单复制 ALiBi 的固定 head distance assignment，而是形成更 context-dependent 的局部注意力。

## Attention Entropy

### 说明

Attention Entropy 衡量 attention 分布的分散程度。数值越高，说明注意力更分散；数值越低，说明注意力更尖锐、更集中。局限是低 entropy 不一定更好，可能是有效选择，也可能是过度局部化。

### 结果展示

![Attention Entropy](output/task1/figures/summary/phase3/phase3_seed42_entropy_by_head_layers_x_models.png)

| 模型 | 平均 entropy | distance pattern consistency | entropy pattern consistency |
|---|---:|---:|---:|
| `rope` | 4.1559 | 0.0058 | -0.0052 |
| `pope` | 3.4314 | 0.0281 | 0.0147 |
| `mod_pope` | 3.8919 | -0.0053 | 0.0095 |
| `alibi` | 2.6298 | 0.9900 | 0.9486 |
| `cable` | 2.5687 | 0.0032 | -0.0057 |

`cable` 的 entropy 最低，甚至略低于 `alibi`，说明它产生了非常集中的 attention；但它的 head pattern consistency 接近 0，与 `alibi` 的 0.95 左右完全不同。这说明 `cable` 的尖锐注意力不是固定 head 模板重复，而更可能随上下文变化。`mod_pope` 的 entropy 高于 origin `pope`，接近 RoPE，进一步说明 modified PoPE 缓和了 origin PoPE 的局部化/尖锐化。

从形态上看，`alibi` 的每层 head 相对比例非常稳定；`cable` 则更像低 entropy 但形状不固定的模型。这是新增 `cable` 后最有价值的机制现象之一：它保留了强位置归纳偏置带来的局部选择性，但没有继承 ALiBi 的固定斜率 head 模板。

### 说明

Attention Heatmap 展示具体 layer/head 的 attention 权重矩阵形态。它适合观察局部斜带、长程跳跃、sink、块状结构等形态特征。局限是 heatmap 是局部样本和局部 head 的可视化，不能单独作为全局结论。

### 结果展示

![Attention Heatmap H0](output/task1/figures/summary/phase3/phase3_seed42_attention_heatmap_head0_layers_x_models.png)

![Attention Heatmap H1](output/task1/figures/summary/phase3/phase3_seed42_attention_heatmap_head1_layers_x_models.png)

Heatmap 的形态与数值指标一致：`rope` 更容易出现较宽的注意力区域和远程关注；`alibi` 更接近稳定局部斜带；`pope` 更局部；`mod_pope` 相比 origin `pope` 斜带更宽，说明 attention 距离确实被拉长；`cable` 则呈现尖锐、局部但不固定重复的形态。这里不能只看颜色强弱，还要看结构形状：`alibi` 的重点是“跨层重复的 head 尺度模板”，`cable` 的重点是“低熵局部但模板不重复”。

## Toeplitz Deviation

### 说明

Toeplitz Deviation 衡量 attention logits 是否接近只由相对距离决定。数值越低，说明同一相对距离 diagonal 上的 logits 更一致；数值越高，说明同一相对距离内部也有更强内容/上下文差异。局限是该指标受 logit 尺度影响较大，尤其不同 bias 形式之间不一定能直接按绝对值比较。

### 结果展示

![Toeplitz Deviation|997](output/task1/figures/summary/phase3/phase3_seed42_toeplitz_deviation_by_head_layers_x_models.png)

| 模型 | Toeplitz deviation |
|---|---:|
| `rope` | 1.7304 |
| `pope` | 1.6134 |
| `mod_pope` | 1.1552 |
| `alibi` | 2.4524 |
| `cable` | 49960.0938 |

`mod_pope` 的 Toeplitz deviation 最低，说明 modified PoPE 在当前计算方式下最接近规则的相对位置结构；origin `pope` 也低于 RoPE。这个结果支持 PoPE 系列确实改变了相对位置结构，而不是只改变训练 loss。

`cable` 的数值极端大，不能和其它模型按同一尺度简单比较。这更可能反映 Cable bias/logit 的尺度和 context-aware 项造成 diagonal 内方差巨大，而不是简单表示“最差”。结合 entropy 和 distance 看，`cable` attention 非常尖锐且局部，但 Toeplitz deviation 巨大，说明它不是稳定的相对距离模板，而是把上下文差异强烈写进 logits。

## Attention Sink Mass

### 说明

Attention Sink Mass 衡量 attention 是否集中到序列开头等固定位置。数值越高，说明存在更强 sink 倾向；数值越低，说明注意力没有大量塌缩到固定开头位置。局限是 sink 有时也可能承担全局 anchor 功能，不一定是坏现象。

### 结果展示

![Attention Sink Mass](output/task1/figures/summary/phase3/phase3_seed42_attention_sink_mass_by_head_layers_x_models.png)

| 模型         | attention sink mass |
| ---------- | ------------------: |
| `rope`     |              0.0058 |
| `pope`     |              0.0035 |
| `mod_pope` |              0.0044 |
| `alibi`    |              0.0039 |
| `cable`    |              0.0038 |

五个模型的 sink mass 都很低，说明当前差异不是由 attention sink 主导。`rope` 略高，`pope` 最低，`mod_pope` 居中。对本文来说，真正区分模型的不是 sink，而是 distance、entropy、local/far mass 和 head-wise pattern consistency。

# 第三阶段：SAE 重构与特征健康

## SAE Validation MSE

### 说明

SAE Validation MSE 衡量 SAE 对 held-out residual activation 的重构误差。数值越低，说明当前 TopK SAE 更容易重构该层 residual；数值越高，说明 residual 表示更难被当前稀疏字典捕获。这里的 SAE activation site 是 block 输出后的 residual 表示，不是 Q/K 或 attention logits。

### 结果展示

![SAE Validation MSE](output/task1/figures/summary/phase4a/phase4a_validation_mse_mean.png)

| 模型 | L2 | L6 | L10 | 平均 |
|---|---:|---:|---:|---:|
| `rope` | 0.2189 | 0.2712 | 0.3013 | 0.2638 |
| `pope` | 0.2767 | 0.2893 | 0.3060 | 0.2907 |
| `mod_pope` | 0.2623 | 0.2786 | 0.3033 | 0.2814 |
| `alibi` | 0.2154 | 0.3040 | 0.3123 | 0.2773 |
| `cable` | 0.2281 | 0.2958 | 0.3110 | 0.2783 |

`rope` 平均 MSE 最低，仍是当前 TopK SAE 最容易重构的表示。`mod_pope` 相比 origin `pope` 有明显改善，平均 MSE 从 0.2907 降到 0.2814，尤其 layer 2 从 0.2767 降到 0.2623。这说明 origin PoPE 的 magnitude softplus 确实可能增加了早层 residual 的 SAE 重构难度。

但 `mod_pope` 仍没有超过 `rope`，也没有超过 `alibi/cable` 的平均水平。这说明 PoPE 系列的共同机制，也就是用 position phase 接管 Q/K pair direction，仍可能让最终 residual 对 SAE 不够友好。形态上，`alibi` 和 `cable` 都是浅层 MSE 低、中深层迅速上升；`rope` 曲线最平滑；`pope/mod_pope` 从浅层开始就偏高，其中 `mod_pope` 缓和但没有根除。

## SAE Explained Variance

### 说明

Explained Variance 衡量 SAE 重构解释原 activation 方差的比例。数值越高，说明 SAE 捕获残差表示结构越充分；数值越低，说明有更多变化没有被当前稀疏字典解释。

### 结果展示

![SAE Explained Variance](output/task1/figures/summary/phase4a/phase4a_explained_variance_mean.png)

| 模型 | L2 | L6 | L10 | 平均 |
|---|---:|---:|---:|---:|
| `rope` | 0.7872 | 0.7336 | 0.7004 | 0.7404 |
| `pope` | 0.7265 | 0.7110 | 0.6875 | 0.7083 |
| `mod_pope` | 0.7417 | 0.7235 | 0.6928 | 0.7194 |
| `alibi` | 0.7868 | 0.6951 | 0.6842 | 0.7220 |
| `cable` | 0.7744 | 0.7049 | 0.6872 | 0.7222 |

排序为 `rope > cable ≈ alibi > mod_pope > pope`。`mod_pope` 相比 origin `pope` 提升约 0.011，说明 modified PoPE 更容易被 SAE 解释；但它仍低于 RoPE。这个结果和 Validation MSE 一致：PoPE 的 softplus magnitude 不是唯一问题，PoPE 的方向替换机制本身也可能降低 residual 的稀疏可重构性。

# 第四阶段：位置/内容解耦分析

### 说明

Raw Position R2 用 raw residual activation 线性回归 normalized position。R2 越高，说明连续位置信息越容易从 residual 中线性读出。当前 R2 多为负值，因此不能作为可靠正证据，应主要依赖分类 probe 的 baseline margin。

### 结果展示

连续位置回归整体不可靠。`mod_pope` 最接近 0，但这不能说明它最好，只能说明当前 linear R2 对 normalized position 的捕捉很弱。后续解释应以 position bin/segment position 的 baseline margin 为主。

# 总结

第一，新增 `cable` 后，训练表现的排序发生了明显变化：`cable` 的 final valid loss 和 perplexity 最好，`alibi` 次之，`rope` 居中，而 `pope/mod_pope` 最弱。这说明更强的位置 bias 在当前训练预算下确实可能改善泛化，但这不等于 SAE 更容易解释。

第二，`mod_pope` 是理解 PoPE 的关键对照。相比 origin `pope`，它提高了 attention distance、提高了 entropy、降低了 SAE MSE、提高了 explained variance 和 SAE seed activation correlation。这说明 origin PoPE 的 magnitude softplus 变换确实让表示更难被 SAE 捕获。但 `mod_pope` 仍没有超过 RoPE，也没有超过 ALiBi/Cable，说明 PoPE 系列共同的“position phase 接管 Q/K direction”机制仍可能让 residual 表示对 SAE 不够友好。

第三，`cable` 和 `alibi` 的差别非常重要。二者都让 attention 变得低 entropy、偏局部，但 `alibi` 的 head-wise distance/entropy pattern consistency 极高，说明它有固定 head 尺度模板；`cable` 的 pattern consistency 接近 0，说明它不是复制 ALiBi 的固定斜率结构，而是形成更上下文依赖的尖锐注意力。这也解释了为什么 `cable` 训练好，但 residual 中 position probe margin 很低：它的位置作用可能主要存在于 attention routing/logits，而不是显式写成 SAE 可读的位置 feature。

第四，SAE 结果仍然不支持“训练性能越好，SAE 越适合”的简单关系。`cable` 训练最好，但 SAE explained variance 只接近 ALiBi，低于 RoPE；`rope` 训练不是最好，但 SAE 重构和跨 seed activation stability 最好。这支持本文核心观点：位置编码影响的不只是模型性能，也影响 residual representation 是否适合被 SAE 稀疏分解。

第五，PoPE 系列的解耦结果需要谨慎表述。`pope/mod_pope` 的 mixed ratio 和 content-position score correlation 更低，说明当前 feature score 下内容与位置更少共同出现；但它们的 SAE position margin、token identity margin、explained variance 都不占优。因此更准确的结论不是“PoPE 更适合 SAE”，而是“PoPE 系列改变了内容/位置 score 的耦合方式，但这种解耦没有转化为更好的 SAE 可重构性或更强的位置 feature 可读性”。

总体而言，目前最有价值的论文叙述是：`ALiBi` 提供固定 head 尺度模板，`Cable` 提供更 context-dependent 的强局部注意力，`RoPE` 产生最适合当前 TopK SAE 重构的 residual 表示，而 `PoPE/mod_pope` 虽然降低了一些 feature-level 内容/位置相关性，却削弱了 SAE 重构和 token identity 保留。这个结果能够支撑本文主题：不同位置编码改变了位置结构进入 attention 与 residual stream 的路径，而 SAE 捕获到的是这些路径在 residual 表示中的后果，不是位置编码理论形式本身。
