# 当前实验设计

## 第一阶段：数据处理

使用 `Skylion007/openwebtext` 作为语料，采用 GPT-2 tokenizer；将文本拼接后切成长度为 1025 的 block，其中前 1024 个 token 作为输入、后移一位作为标签；当前配置为训练集 50000 blocks、验证集 5000 blocks，输出缓存后的 `train/valid` BlockDataset 和数据元信息。

## 第二阶段：模型构建

构建 GPT-like causal Transformer，统一使用 12 层、768 hidden size、12 heads、3072 FFN、词表 50257、序列长度 1024；位置编码组包括 `std`、`rope`、`pope`、`alibi`，当前已产出的主结果表主要覆盖 `rope` 与 `pope`，输出模型对象、参数统计和位置编码配置记录。

## 第三阶段：语言模型训练

对每个位置编码模型从头训练 next-token prediction；当前配置 seed 为 42、训练 100000 steps、batch size 8、AdamW、学习率 \(6e{-5}\)、1000 step warmup、cosine decay、bf16；输出 checkpoint、loss curve、valid loss、perplexity，以及 RoPE/PoPE 的 paired summary 表。

## 第四阶段：注意力机制分析

在训练模型上抽取验证集注意力，分析 attention entropy、attention distance、local/far attention mass、spectral concentration 和 Toeplitz deviation；代表层为 1、6、10，代表头为 0、1、2、3，输出注意力热图、谱图和 Phase 3 指标表。

## 第五阶段：SAE 训练

在第 2、6、10 层的 `residual_post_block` 激活上训练 TopK-SAE；每层最多收集 65536 个训练激活 token、16384 个验证激活 token，字典大小 4096，Top-K 为 64，训练 2000 steps；输出 SAE checkpoint、重构误差、explained variance、dead feature rate 和 feature health 统计。

## 第六阶段：解耦评价

用原始激活和 SAE feature 分别预测位置与 token/category 信息，指标包括 position \(R^2\)、position-bin accuracy、token-category accuracy、互信息、相关性和 feature selectivity；训练 probe 使用 8192 个 token，验证使用 4096 个 token，输出 Phase 5 disentanglement summary 和 feature-level score 表。

## 第七阶段：自动解释

从每个模型、层和标签类别中抽取最多 20 个 SAE feature，收集每个 feature 最多 12 个高激活上下文，调用 `gpt-4o-mini` 生成 feature 解释并标注 `content_only`、`position_only`、`mixed`、`low_selectivity`；输出 prompt、解释记录和 Phase 6 解释评分表。
