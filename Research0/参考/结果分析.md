### 关于 sparse FFN 的计算成本改进

当前 `sparse12ffn` 的实现是：

```text
x -> dense up: 384 -> 1536
  -> GELU
  -> topk 保留 192 个激活
  -> dense down: 1536 -> 384
```

因此它是行为稀疏，但不是计算稀疏。`up` 和 `down` 仍然按完整 `1536` 维计算，还额外增加了 `topk`、mask 等操作，所以训练成本会高于 `base`。

真正降低计算成本，需要在计算前决定哪些 FFN 单元要参与，而不是算完后再置零。

| 方法 | 原理 | 优点 | 风险 |
|---|---|---|---|
| 结构化稀疏 | 将 `1536` 个 FFN hidden units 分成固定 group，每次只计算部分 group | 规则、容易解释、较容易实现真实加速 | 选择不够灵活，可能损失模型能力 |
| predictor 预测 | 用一个小模块根据输入预测哪些 neuron/group 重要，然后只计算这些部分 | 动态、表达能力更强 | 引入 routing 变量，实验解释更复杂 |
| 论文中的加速 sparse FFN | 通常结合结构化稀疏、近似 top-k、predictor 或硬件友好的 sparse kernel | 能把稀疏转化为真实 FLOPs / wall-time 收益 | 工程复杂度更高，不适合直接替代当前 ablation |

对当前实验来说，最适合的下一步是做一个结构化版本：

```text
structured_sparse12ffn:
1536 hidden dim -> 8 groups
每次只计算 1 group，也就是 192 / 1536 = 12.5%
```

需要对比：

| 模型 | 目的 |
|---|---|
| `base` | 标准对照 |
| `sparse12ffn` | 当前 mask 版，验证 SAE 重构提升 |
| `structured_sparse12ffn` | 测试是否能同时降低计算成本并保留 SAE 提升 |
| `top16attn + structured_sparse12ffn` | 测试是否能兼顾学习效果、计算成本和 SAE 重构 |

## 理论来源说明

`sparse12ffn` 不是严格复现某一篇论文的完整实现，而是一个用于验证假设的简化 ablation。它主要借用了 sparse FFN / activation sparsity 的思路：FFN 中间层只有一部分 neuron 对当前 token 真正重要，因此可以只保留 top-k 激活。

最接近的论文思路是 `Spark Transformer: Reactivating Sparsity in FFN and Attention`。这篇论文把 FFN 看成 key-value lookup，使用 top-k masking 控制 FFN 激活稀疏度，并进一步用 statistical top-k 和低成本 predictor 来避免标准 top-k 排序带来的训练/推理开销。

但当前代码实现和 `Spark Transformer` 不一样。当前 `SparseFFN` 是：

```text
x -> dense up: d_model -> d_ff
  -> GELU
  -> torch.topk 选出 k 个激活
  -> mask 其余激活为 0
  -> dense down: d_ff -> d_model
```

也就是说，当前实现仍然先完整计算 `up`，再做精确 `torch.topk`，最后 `down` 也是普通 dense matmul。因此它是行为稀疏，不是论文中的真正计算稀疏版本。

它也不同于 `DejaVu: Contextual Sparsity for Efficient LLMs at Inference Time`。`DejaVu` 的核心是用低成本 predictor 在计算前预测哪些 MLP 参数/attention heads 重要，并结合硬件友好实现获得 wall-time 加速；当前 `sparse12ffn` 没有 predictor，也没有跳过完整 FFN 计算。

它同样不同于 `To 2:4 Sparsity and Beyond: Neuron-level Activation Function to Accelerate LLM Pre-Training`。那篇 2026 年论文用的是硬件支持的 `2:4` 权重稀疏和 `v:n:m` activation sparsity，并配合 sparse training / dense ending 训练流程；当前实现没有用结构化硬件稀疏 kernel。

所以本文里的 `sparse12ffn` 更准确的定位是：受 sparse FFN / top-k activation sparsity 启发的实验组，用来测试“FFN 激活稀疏化是否有利于 SAE 重构”，而不是计算加速论文的完整复现。

- `groupmix2ffn` 的综合性最好：SAE 重构提升 `50.76%`，训练成本增加 `10.2%`，LM 损失为 `-1.914%`。它适合作为下一轮主线。
- `groupmix4ffn` 的 SAE 重构提升最高，为 `71.03%`，但 LM 损失更大，并且 feature ablation 指标下降，更像是把表示压得更简单，而不一定让 SAE 特征更有因果价值。
- `structured25ffn` 虽然 SAE 重构略有提升，但训练成本增加 `50.5%`，学习效果下降 `4.030%`，不建议继续。
- 后续实验建议围绕最佳验证点做 SAE，而不是固定用 `120000 step` 末尾模型；本轮多数模型最佳验证点出现在 `35000-55000 step`，继续训练到 `120000 step` 后已经出现明显过训练。

`causal isolation` 的聚合是：

```text

------------------------------------------------
```

## 分析

### 总体结论

Task6 能可靠支持三个结论：

1. SP 在几乎不改变参数量、基本保持语言模型质量的情况下，将 FFN 激活密度从 100% 降至约 9.1%。
2. SP 在两种位置编码、所有五个 SAE k 上都显著降低 normalized MSE，证明 SP 表征具有更好的稀疏可压缩性。
3. 稀疏可压缩性没有自动转化为所有可解释性指标的提升：context coherence、absorption、FADE faithfulness proxy 和部分 causal necessity 改善，但 Concept AUPRC、hard-negative separation、feature usage、decoder duplication 与 causal sufficiency isolation 出现混合或恶化结果。

因此最准确的表述是：

> SP 稳定提高 FFN 结构稀疏性和 SAE 稀疏重构效率，并改善部分语义一致性与因果必要性指标；但其可解释性收益受到位置编码调节，并伴随特征边界区分度及因果充分性隔离度的下降。

### 改进部分及可能原因

#### 1. FFN 稀疏性提高约 90.9%

这是 Task6 最直接、最没有歧义的改进。SPFFN 使用 predictor/value 分支和 statistical threshold，使每个 token 最终只有约 `139-141 / 1536` 个 FFN 单元非零。RoPE 与 CABLE 下得到几乎相同的 density，说明 FFN 稀疏性主要由 SPFFN 机制本身决定，而不是位置编码偶然造成。

可能原因：

- `k_ratio=0.08` 直接约束了被保留的候选规模。
- soft threshold 在保留主要响应的同时压掉大量低响应单元。
- 两种位置编码只改变 Attention，不直接改变 SPFFN 的阈值公式，因此最终 FFN density 高度一致。

#### 2. SAE normalized MSE 在 SP 中提高约 23%-26%

这是最稳定的跨网格结果。相同 `actual L0` 下，SP 的 hidden representation 更容易被 TopK SAE 重构。

可能原因：

- SP 模型的 FFN 激活由少量单元主导，使下游 hidden state 的有效维度或有效秩下降。
- 表征能量可能更集中在少量方向，SAE 用固定数量的 latent 更容易覆盖主要方差。
- SP 的门控结构可能减少大量低幅度、分散但对 MSE 有贡献的成分，从而改善 SAE 的几何重构。
- CABLE 进一步限制注意力的有效 token 数，可能让上下文聚合更加集中，因此 `sp_both_cable` 得到最低 normalized MSE。

这些原因目前是与结果一致的解释，还需要通过 covariance spectrum、effective rank、participation ratio 和 activation tail 分布验证，不能直接当成已证明机制。

#### 3. CABLE 改善模型质量和注意力集中度

`base_cable` 与 `sp_both_cable` 的 valid CE 都优于 `base_rope`；CABLE 还显著降低 Attention entropy 和 effective tokens。

可能原因：

- CABLE 根据当前 hidden state 生成内容依赖的累积位置偏置，形成单调的距离惩罚。
- 对 OWT 的短上下文语言建模，较强的局部/近因偏置可能与数据分布匹配，因此降低 CE。
- 在 SP Attention 中，CABLE bias 只进入 predictor score，可能帮助 predictor 更稳定地筛选上下文位置，从而得到 `sp_both_cable` 的最低 effective-token 指标。

需要注意：Task6 没有真正的 Attention Top-k 剪枝，因此这里只能解释为注意力集中机制，不是结构稀疏加速。

#### 4. SP 改善 context coherence 与 low-coherence rate

`sp_both_rope` 的平均 context coherence 提高 `11.24%`，low-coherence rate 相对降低 `40.94%`；`sp_both_cable` 也分别改善 `7.02%` 和 `22.45%`。

可能原因：

- SP 表征更集中，使同一个 SAE latent 的高激活上下文在 hidden space 中更接近。
- SAE 更低的重构误差减少了 latent 激活中的重构噪声，使 top examples 看起来更一致。
- 一部分原本分散在多个弱方向上的上下文被更少的主方向吸收，提升了特征内部一致性。

但 coherence 只表示“同一特征的样例更像”，不等于“这个特征与相邻特征更容易区分”。Hard-negative 结果说明这两者在 Task6 中发生了分离。

#### 5. Absorption 多数改善

相较 `base_rope`，`sp_both_rope` 的 absorption rate 降低 `25.57%`，`sp_both_cable` 降低 `8.55%`，说明部分父概念不再需要多个候选特征才能补回漏检样例。

可能原因：

- SP 的特征内部一致性提高，使同一概念的样例更可能由同一 latent 覆盖。
- 更低 SAE MSE 使原本落入 reconstruction residual 的概念信息被 latent 捕获。
- RoPE 下的效果强于 CABLE，可能说明 RoPE 同时作用于 SP predictor/value 两个子空间，更有利于形成跨上下文一致的概念方向。

#### 6. 因果必要性隔离度在 SP 中改善

主操作点下，`sp_both_rope` 的 necessity isolation 提高 `7.82%`，`sp_both_cable` 提高 `3.55%`（统一基准）。“移除概念相关特征”能够用较小或相近的全局 KL，造成更强的目标概念下降。

可能原因：

- SP 的概念信息更集中在少量活跃方向，移除这些方向时目标行为下降更明显。
- `sp_both_rope` 的 necessity target effect 略低于 base，但 KL 降低约 `20.48%`，因此隔离度提高，说明其主要优势来自干预更局部。
- `sp_both_cable` 的 target effect 高于 base，但 KL 也略高，最终仍保留小幅 isolation 收益。

#### 7. FADE faithfulness proxy 改善

`sp_both_rope` 提高 `18.64%`，是四组中最明显的结果；`base_cable` 与 `sp_both_cable` 也分别提高约 `6.21%` 和 `7.23%`。

可能原因：

- 更集中的 latent activation 使特征强度与 next-token 行为变化之间更稳定。
- RoPE 同时作用于 predictor/value 子空间，可能使特征方向与输出行为的耦合比仅向 predictor 加 CABLE bias 更一致。

但当前只是 next-token proxy，且没有完整 annotation-backed/open-vocabulary FADE，因此不能等同于自然语言解释质量已经提高。

### 恶化部分及可能原因

#### 1. Hard-negative separation failure 明显恶化

当前代码里的 hard negative 不是人工构造的语义负例，而是：

```text
SAE encoder preactivation > 0
但在 TopK 竞争后实际 latent activation = 0
```

对每个特征，评估取最高激活正例和 preactivation 最高的被抑制候选，分别计算 context coherence：

```text
hard-negative margin
= positive context coherence - suppressed-candidate context coherence
```

当 margin `< 0.05` 时计为 failure。

| 模型 | Positive coherence ↑ | Mean margin ↑ | Failure rate ↓ | 相较 base |
|---|---:|---:|---:|---:|
| `base_rope` | 0.6012 | 0.2498 | 6.30% | 0.00 pp |
| `base_cable` | 0.6028 | 0.2531 | 8.24% | 恶化 1.94 pp |
| `sp_both_rope` | 0.6688 | 0.1993 | 21.43% | 恶化 15.13 pp |
| `sp_both_cable` | 0.6434 | 0.2225 | 15.09% | 恶化 8.79 pp |

SP 的正例 coherence 明显提高，但 margin 反而下降。这意味着 SP 让真正激活样例更加“成团”的同时，也让 TopK 边界外的候选样例变得更像正例。

可能原因：

- SP 降低表示的有效维度后，多个相邻 latent 可能争夺高度相似的上下文。
- 固定 TopK 必须在多个接近候选之间做离散选择，最终选中与未选中的语义边界不再清晰。
- SAE normalized MSE 的优化目标鼓励重构，不直接要求每个 latent 具有独立语义边界。
- SP 的 feature usage entropy 下降、decoder duplication 增加，与“少数方向集中、相邻特征更重叠”的解释一致。

不过该指标本质上是 SAE TopK 边界可分离性 proxy，不是直接的人工语义特异性。需要 Anthropic-style contrastive/sort eval 或人工盲审确认这些被抑制候选在人类语义上是否真的难以区分。

#### 2. 因果充分性隔离度恶化

充分性测试在概念负例中移除相关特征的原贡献，再注入概念正例上的平均特征贡献，测量目标概念 log-odds 是否上升。之后减去频率匹配随机特征的效应，并除以全词表 KL 的平方根：

```text
sufficiency isolation
= control-adjusted target effect / sqrt(global KL)
```

Task6 的关键现象不是 SP 无法改变目标行为，而是目标行为与全局输出分布一起变化得太多：

| 配对 | Target effect 变化 | Global KL 变化 | Isolation 变化 |
|---|---:|---:|---:|
| `sp_both_rope` vs `base_rope` | +21.63% | +57.15% | -2.97% |
| `sp_both_cable` vs `base_cable` | +46.02% | +224.04% | -18.88% |

可能原因：

- SP 特征方向可能同时连接多个输出行为，注入单一概念特征时会改变大量非目标 token。
- 部分 latent 可能是多个基础概念的组合，而不是原子概念；这与 decoder duplication、hard-negative failure 的恶化方向一致。
- 将正例平均激活直接注入负例可能产生 off-manifold hidden state；SP/CABLE 表征对这种分布外干预可能更敏感。
- CABLE 在 SP 中只改变 predictor score，而 value branch 没有相同位置偏置，可能使“选择哪些上下文”和“如何影响输出”之间耦合不足。
- `sp_both_cable` 的目标充分性效应最强，但 KL 增幅远高于目标效应增幅，因此它更像“容易被强力 steering”，而不是“能够被局部、精准地 steering”。

需要强调，当前 KL 包含目标 token。后续如果要严格证明 off-target locality，应补充排除目标词集合后的 KL、无关概念 log-odds 变化和通用能力保持，而不是只依赖当前 isolation ratio。

#### 3. Concept AUPRC 没有统一改善

统一相较 `base_rope`，`base_cable / sp_both_rope / sp_both_cable` 的 Concept AUPRC 分别下降 `7.53% / 7.39% / 4.29%`。但按相同位置编码配对，`sp_both_cable` 又比 `base_cable` 高 `3.51%`，说明结果存在明显 interaction：

- RoPE 下 SP 改善 context coherence，却降低已知概念检测。
- CABLE 下 SP 能提高 Concept AUPRC，但仍没有超过 `base_rope`。
- 当前固定概念词表很小，无法覆盖 open-vocabulary 特征；因此 AUPRC 只能衡量预设概念可分性，不能代表全部 SAE 特征的可理解程度。

可能原因：SP 学到的特征可能更偏向上下文模式、句法结构或复合语义，而不是当前词表中的 token-level 类别；也可能是特征更成团但边界更宽，造成 hard negative 与概念负例上的误激活。

#### 4. Feature usage、duplication 和单特征消融效应恶化

SP 在 k=64 下仍有约 99.8%-99.9% fraction alive，但 feature usage entropy 下降 `4.08%-5.36%`，decoder duplication 增加 `4.68%-6.35%`，feature ablation loss delta 下降 `6.31%-11.71%`。

可能原因：

- 大多数 latent 虽然都活着，但激活频率更加不均衡。
- 多个 decoder direction 可能表示相近或重叠的信息。
- 模型行为由一组相关特征共同承担，单独消融一个特征时影响较小。

这说明“fraction alive 接近 1”不足以证明特征集合健康，必须同时报告 usage entropy、duplication、absorption 与单特征因果效应。

#### 5. 训练与 SAE 评估成本显著增加

SP 两组相较统一 base 的训练成本增加 `61.3%-65.3%`，五组 SAE 总时间增加 `71.2%-73.8%`。这并不是 SAE 本身参数规模突然增大，而是 SAE 训练和评估需要反复运行更慢的 SP 基模型来采集 activation、计算重构后的 LM loss 和执行 feature ablation。

当前 SP 是数学参考实现而非 sparse kernel 实现，因此不能把约 91% 的 FFN activation sparsity 转换为 wall-time 加速。若论文不实现专用 Triton/CUDA kernel，应将效率结果定位为实现成本与限制，不应声称实际加速。

### 位置编码机制结论

Task6 表明 CABLE 的作用不是统一的“更好”或“更差”：

- 在 Base 和 SP 中都改善 valid CE 和 Attention concentration。
- 在 SP 中进一步改善 normalized MSE 与 loss recovered。
- 在 SP 中缓解 hard-negative failure：`21.43% → 15.09%`。
- 但在 SP 中使 sufficiency isolation 从 `2.6531` 降至 `2.2519`，说明 steering 的全局扰动显著增加。
- `sp_both_rope` 的 context coherence、absorption 和 FADE faithfulness 更好；`sp_both_cable` 的模型质量、SAE fidelity 和 Concept AUPRC 更好。

因此位置编码适合作为论文中的第二个独立变量，而不是简单的附加实验。最终统计模型应报告：

```text
metric ~ architecture(Base/SP)
       + position(RoPE/CABLE)
       + architecture × position
       + model_seed random effect
```

### 统计与结论边界

- 当前只有一个独立模型 seed，所有 paired test 的置信区间退化，`p=1` 不表示不存在差异，而表示无法执行有效的 seed-level 显著性检验。
- 当前只有一个 SAE seed，没有 PW-MCC/Hungarian 跨 SAE seed 稳定性结果。
- 每组导出了 100 个人工审核项目，但 `human_annotations_available=False`，尚未形成盲化人工证据。
- 完整 open-vocabulary FADE 没有运行，目前是自动 proxy。
- 四组的主操作点都落在 k=64，现有 k-grid 无法比较更精细的 matched-fidelity L0。
- 所有模型的最佳 valid CE 都出现在 60000 step。曲线已接近平台但仍缓慢下降，足够用于本轮公平对比，不能严格断言完全收敛。

Task6 当前可以支持：

> SP 显著提高 FFN 激活稀疏性，并稳定提高相同 SAE L0 下的稀疏重构效率；CABLE 调节这种收益能否转化为 LM fidelity、概念检测和因果作用。

Task6 当前不能支持：

> SP 或 CABLE 无条件提高整体可解释性，或者 SP Attention 已经实现真实结构稀疏与运行加速。

更适合顶会论文的最终主张是：

> 结构稀疏稳定改善 SAE 可压缩性，但可解释性收益并非自动产生，而是受到位置编码调节，并在特征内部一致性、边界特异性与因果局部性之间形成可测量的权衡。

## 分析

### 结论

fast-SP 成功解决了原始 SP 参考实现“稀疏但不省时间”的一部分问题。RoPE 的实际训练时间相对原始 SP 降低 `47.3%`；受控 benchmark 中，时间降低 `8.58%-47.07%`，显存降低 `46.49%-76.80%`。

但当前版本没有实现相对 base 的真实加速。实际训练时间仍高 `5.7%-12.5%`，受控 benchmark 仍高 `17.76%-76.14%`。标准 RoPE/SDPA 的融合 dense kernel 很高效，而窗口 mask、FlexAttention 编译或 fallback 路径仍有额外开销。当前输出也没有记录 fast-SP 最终使用的是 FlexAttention 还是异常后的 SDPA fallback，因此还不能定位具体 kernel 瓶颈。

### 学习效果下降的原因

当前 fast-SP 不是原始 SP 的等价快速 kernel，而是更激进的近似结构：

- FFN 从 `d_ff=1536` 的完整参数库改成物理宽度 `128` 的紧凑 GLU，总参数减少 `20.70%`，单 block 参数减少 `58.28%`。
- Attention 从内容相关的 SP predictor/value 机制改为固定长度 256 的局部窗口，远距离 token 无论内容多重要都无法被选择。
- 原始 SP 的第二套 value-score gate 被标准窗口 attention 取代，机制本身发生变化。

因此，fast-SP 相对 base 的学习效果下降 `3.53%-4.94%`，明显差于原始 `sp_both_rope` 的 `-1.49%`。这更像容量和机制被压缩过度，不是简单的训练不足。虽然曲线在 60000 step 仍缓慢下降，但 `base_rope` 在 25000 step、`base_cable` 在 30000 step 就已经达到或超过对应 fast-SP 训练 60000 step 的最终 CE，所以按达到相同模型质量计算，fast-SP 也没有成本优势。

CABLE 对 fast-SP 有一定缓解：相对各自 base 的学习损失从 RoPE 的 `4.94%` 缩小到 `3.53%`，改善约 `1.41` 个百分点。不过 fast-SP 目前只有一个 seed，这个交互只能视为初步信号。

### 是否值得继续

当前 fast-SP 值得保留为“硬件友好稀疏近似”的工程基线，但不适合直接替代原始 SP，也暂时不值得立即投入完整 SAE 与可解释性评估。下一步应先提高 `active_width` 到 `256/384`、测试 `window_size=512`，并拆分 `fast_sp_attn + std_ffn` 与 `std_attn + fast_sp_ffn`，确认质量损失主要来自哪一部分。同时应把实际执行的 Attention backend 写入输出；只有当 Valid CE 损失压到约 `1%-2%` 内，再补齐三个模型 seed 和 SAE 网格才划算。

## 分析

### 总体判断

1. `sp_both_cable` 是本轮最值得继续的科学实验组。它在三个 seed 上稳定改善 Valid CE，固定 k=64 时学习效果提高 `1.332%`、SAE MSE 提高 `13.57%`、Concept AUPRC 提高 `1.76%`、necessity isolation 提高 `10.67%`；但训练和 SAE 成本分别增加 `267.74%` 和 `298.37%`，sufficiency isolation 下降 `18.05%`。
2. `fast_sp_both_cable` 是值得继续调参的效率实验组。它在 CABLE 长上下文路径中的绝对 benchmark 时间明显低于原始 SP 和 `base_cable`，SAE MSE 相对统一基准提高 `41.90%`；但相对 `base_rope` 仍未实现加速，语言模型质量下降 `3.025%`，causal necessity/sufficiency isolation 下降 `42.98%/40.09%`，当前不能替代原始 SP。
3. `sp_both_rope` 适合保留为位置编码对照。它的 SAE MSE 改善跨全部 15 个配对成立，但学习效果下降 `1.31%`，实际训练成本增加 `232%`，且 hard-negative 与 sufficiency isolation 明显恶化。
4. `fast_sp_both_rope` 的工程价值较弱。它几乎没有降低本轮实际训练时间，隔离 benchmark 仍慢于 base，语言模型质量却下降 `4.26%`。除非用于拆分 Attention/FFN 归因，否则不应作为主线模型。

### 机制解释

原始 SP 保留完整参数容量，并通过 predictor/value 分支形成约 `9.1%` 的 FFN 激活密度，因此 CABLE 下能够同时保持甚至改善模型学习。但当前实现仍执行 dense value/down 和完整 score 计算，结构稀疏没有转化成 wall-time 节省。

fast-SP 将 FFN 物理宽度降到 128，并把内容相关 SP Attention 近似成固定 256 窗口。它确实减少参数、显存和长上下文计算，却同时降低模型容量并删除远距离内容路由。这可以解释为什么 hidden state 更低维、更容易被 SAE 重构，但语言模型质量与因果局部性反而下降。

CABLE 是关键调节变量：以统一基准看，它让原始 SP 从 RoPE 下 `-1.309%` 的学习损失变成 `+1.332%` 的学习提升；长度 2048 时也把 fast-SP/CABLE 的绝对 block 时间压到 `3.5479 ms`。但 CABLE 本身相对 `base_rope` 成本很高，也没有解决 fast-SP 的容量损失和因果副作用。

### 统计边界

- 三个模型 seed 已能判断方向一致性，但仍低于配置要求的 `10` 个独立 seed；四项预注册 paired test 经 FDR 校正后均未显著。
- `sp_both_cable` 的 Concept AUPRC 和 necessity isolation 三 seed 差值方向一致，但精确置换检验最低只能得到 `p=0.25`，不能写成统计显著。
- 当前只有一个 SAE seed，没有 SAE 字典稳定性证据。
- `no_explanation` 仍受有限概念词表约束；FADE 是 next-token proxy；人工审核包已导出但没有人工标注。
- fast-SP 的 MSE 改善可能部分来自模型容量和表示有效维度下降。论文中应表述为“更容易稀疏重构”，不能直接等同于“特征更可解释”。

本轮最稳妥的结论是：

> 原始 SP 与 CABLE 的组合在保持语言模型质量的同时，提高了 SAE 重构效率和部分语义/因果必要性指标；硬件友好的 fast-SP 能显著降低原始 SP 的长上下文成本，但其更强的 SAE 重构优势伴随模型能力和因果局部性的明显损失。
