# 引言
### 上个实验的教训
- 上次实验主要尝试通过修改位置编码来解耦位置与内容之间的关系，从而让 SAE 获得更清晰、更可解释的特征表示。对比了`RoPE, PoPE, Alibi`三种位置编码
- 但实验结果表明，解耦位置与内容的效果并不理想，得出以下几点结论：
	1. 模型需要位置内容深度耦合来学习更深层次的语义特征
	2. 位置解耦只是众多叠加语义特征中微不足道的一个特征
	3. 即使在位置编码解耦，真正融合学习语义特征的机制有可能是attention 和 FFN
### 本次实验的目的

- 我们先确定我们的目标：
	1. 诱导模型学习更加稀疏，单义的语义特征维度，方便提升SAE的可解释性
	2. 尝试在前者的基础上诱导模型学习出层级机构或者是可以承载稳定因果关系的特征表示，以期支持模型高效举一反三泛化干预
	3. 最终目标是，诱导模型形成可解释，可审计，可干预的特征表示
	
- 然后为了实现我们的目标，我们预计作以下实验：
	1. 修改`Attention`机制        （token交互）
	2. 修改`FFN`机制                   （更新token特征表示）
	3. 修改`Loss`机制                 （控制模型学习的目标）

# 设计
## 总览

第一阶段不追求穷尽所有 Transformer 机制变体，而是用尽可能少的实验组回答一个核心问题：

> 在相同数据、tokenizer、训练 token 数、优化器、模型规模和 SAE 设置下，routing sparsity、FFN modularity、FFN activation sparsity、loss-induced sparsity 哪一种最能改善 SAE 对 residual stream 的解析质量？

因此第一阶段采用 `1 + 4` 的最小实验矩阵：一个 baseline，加四个单变量机制修改组。

| 组别 | 实验组 | 修改位置 | 核心问题 |
|---|---|---|---|
| B0 | Standard Transformer | baseline | 原始 Transformer 在当前数据、模型规模和 SAE 设置下的参照结果 |
| A1 | Top-K Attention | Attention | hard content-based sparse routing 是否能减少 routing superposition，并让 SAE 更容易解析 residual features |
| F1 | Grouped FFN with Limited Mixing | FFN | 模块化 FFN 是否能诱导更解耦的 feature subspace |
| F2 | Sparse FFN | FFN | 直接让 FFN activation 更稀疏，是否能提升 SAE feature 的单义性 |
| L1 | LM + L1 Activation Sparsity | Loss | 通过训练目标施加稀疏压力，是否能改善 SAE feature quality |

选择这四个实验组的理由：

1. `Top-K Attention` 代表 attention 层面的信息路由稀疏化。它比普通 fixed sparse attention 更适合本研究问题，因为 Top-K 是根据当前 token 内容动态选择 key，而不是只按固定位置模式裁剪 attention。
2. `Grouped FFN with Limited Mixing` 代表 FFN 层面的模块化约束。FFN 更直接负责 token-wise feature transformation，因此模块化 FFN 可能比 attention 改动更直接影响 SAE 能否分解出清晰 feature。
3. `Sparse FFN` 代表结构层面的激活稀疏化。它和 SAE 的目标最接近：不是事后用 SAE 找稀疏特征，而是在原模型训练时就让内部激活更稀疏。
4. `LM + L1 Activation Sparsity` 代表 loss 层面的稀疏诱导。它实现成本低、变量少，适合作为判断“稀疏压力本身是否有用”的最小对照。

暂时不选择其他实验组的理由：

1. 暂时不选 `Entmax Attention`。Entmax 是很好的 soft / differentiable sparse routing 对照，但第一阶段如果计算预算有限，优先保留更直接、更锋利的 Top-K；若 Top-K 有明显收益，第二阶段再加入 Entmax 判断 hard sparse routing 是否必要。
2. 暂时不选普通 `Sparse Attention`，例如 Longformer / BigBird 式 fixed sparse attention。这类机制主要为效率和长上下文设计，稀疏的是固定位置连接，不一定能回答“语义相关的信息路由是否更适合 SAE”这个核心问题。
3. 暂时不选 `SwiGLU / Gated FFN`。它是现代 LLM 常用的性能机制，但解释性假设不如 grouped FFN 和 sparse FFN 直接，第一阶段优先选择更贴近 feature modularity / sparsity 的机制。
4. 暂时不选 `MoE FFN`。MoE 有很强的模块化潜力，但会引入 router、expert 数量、load balancing loss、capacity factor 等额外变量，第一阶段容易增加归因难度和训练成本。
5. 暂时不选 `Orthogonality / Decorrelation Loss`。它适合第二阶段加入，尤其当 L1 sparsity 有效果但出现 feature duplication 时，用来进一步减少冗余。
6. 暂时不选 `Hierarchy Loss` 和 `Causal Loss`。这两类目标需要额外标签、数据构造和专门评价任务，应该放在 monosemanticity 初筛之后。第一阶段先回答“什么机制最能提升 SAE 可解析性”，再进入层级表示和因果表示实验。
### Attention 的修改

#### Sparse Attention

Sparse Attention 是一个大类，核心思想是在 attention score matrix 上加入稀疏 mask，减少 token-to-token 的连接数量。

标准 attention 为：

$$
S=\frac{QK^\top}{\sqrt{d_k}},\quad
A=\mathrm{softmax}(S)
$$

Sparse Attention 引入 mask $M$：

$$
a_{ij}^{sparse}
=
\frac{\exp(S_{ij})\mathbf{1}[(i,j)\in M]}
{\sum_{m:(i,m)\in M}\exp(S_{im})}
$$

输出为：

$$
o_i^{sparse}=\sum_{j:(i,j)\in M}a_{ij}^{sparse}v_j
$$

如果 $M$ 是固定位置模式，例如 local window：

$$
M_i=\{j:|i-j|\leq w\}
$$

则该机制主要约束的是位置连接，而不是语义相关性。Longformer / BigBird / Sparse Transformer 等 fixed sparse attention 多数属于这一类。

从 SAE 角度看，Sparse Attention 的潜力在于减少 residual stream 的来源混合，使信息路径更少、更容易追踪。但它的问题是：如果稀疏模式是固定的，它并不保证被保留的 token 是当前 query 语义上最相关的 token。因此 fixed sparse attention 更适合作为效率机制或长上下文机制，而不是第一阶段最强的 interpretability 机制。

因此第一阶段暂时不选择普通 Sparse Attention，而选择更直接的 Top-K Attention。两者区别可以概括为：

| 机制 | 稀疏依据 | 对 SAE 的理论价值 |
|---|---|---|
| Fixed Sparse Attention | 位置规则，例如 window / stride / global token | 减少连接数，但不一定减少语义混合 |
| Top-K Attention | 当前 query-key 相似度 | 直接减少 content-based routing superposition |

#### Top-K Attention

标准 attention 为：

$$
S=\frac{QK^\top}{\sqrt{d_k}},\quad
A=\mathrm{softmax}(S),\quad
O=AV
$$

其中每个 query 位置 $i$ 的输出是：

$$
o_i=\sum_{j=1}^{t}a_{ij}v_j
$$

Top-K Attention 在 causal mask 之后，只保留每个 query 分数最高的 $k$ 个 key：

$$
I_i=\mathrm{TopK}_j(S_{ij}, k)
$$

然后只在这个集合内部重新归一化：

$$
a_{ij}^{topk}=
\begin{cases}
\dfrac{\exp(S_{ij})}{\sum_{m\in I_i}\exp(S_{im})}, & j\in I_i \\
0, & j\notin I_i
\end{cases}
$$

输出变为：

$$
o_i^{topk}=\sum_{j\in I_i}a_{ij}^{topk}v_j
$$

伪代码：

```python
scores = q @ k.transpose(-2, -1) / sqrt(d_k)
scores = scores.masked_fill(causal_mask == 0, -inf)
topk_idx = scores.topk(k, dim=-1).indices
topk_mask = zeros_like(scores).scatter(-1, topk_idx, 1)
scores = scores.masked_fill(topk_mask == 0, -inf)
attn = softmax(scores, dim=-1)
out = attn @ v
```

标准 softmax attention 是 dense routing，即使很多 attention weight 很小，它们通常也不是 0。因此每个 token 的 residual stream 会混入许多来源的信息。这种连续的弱混合可能增加 feature superposition：一个位置中的表示同时携带多条弱相关路径的信息，后续 SAE 需要把这些叠加信息拆开，难度会更高。

Top-K Attention 则将每个 query 的可见 key 限制在相似度最高的 $k$ 个 token 上，只从少数被选中的 token 接收信息。这可能带来几个对 SAE 有利的效果：
1. 信息路径更稀疏。SAE 分解 residual stream 时，面对的是更少来源混合后的表示，可能更容易找到稳定 feature direction。
2. Attention edge 更接近 causal graph 中的边。Top-K 选中的边更适合做 activation patching、path patching 和 feature attribution。
3. 弱相关噪声减少。Dense softmax 会把大量低权重 value 混入表示，Top-K 会截断这些长尾来源，可能降低背景式 polysemantic mixture。
4. 可能促进 head specialization。在 Top-K 约束下，不同 head 可能更稳定地选择不同类型的信息源，例如位置、实体、引用对象、语法关系等，从而让后续 SAE 看到更模块化的 residual features。
但 Top-K Attention 也有一个重要限制：它稀疏的是 routing，不是 feature 本身。模型仍然可能把多个语义功能压进同一个被选中的 value vector，或者把 polysemanticity 转移到 FFN / residual stream 中。因此 Top-K Attention 不一定单独保证 monosemanticity。

可以把核心假设表述为：
> Top-K Attention may be SAE-friendly because it reduces routing superposition before representation superposition is formed, but it is not sufficient for monosemanticity unless combined with feature-space constraints such as sparse FFN, orthogonality loss, or SAE-inspired regularization.
因此，Top-K Attention 更适合作为一种路由层干预变量。它最值得验证的问题不是“Top-K 是否直接产生单义特征”，而是：
- Top-K 是否降低 attention path entropy？
- Top-K 是否让 SAE 在相同 L0 下获得更低 reconstruction loss？
- Top-K 是否提高 SAE feature interpretability score？
- Top-K 是否减少 feature duplication 和 feature splitting？
- Top-K 是否让 feature ablation 的影响更局部？
- Top-K 是否让 SAE feature 更容易对应具体 attention path？
- Top-K 带来的 LM loss 代价是否可接受？
直觉上，三种方案的潜力排序可能是：
$$
\text{Top-K attention alone}
<
\text{Top-K + sparse FFN}
<
\text{Top-K + sparse/orthogonal loss}
$$

也就是说，Top-K Attention 本身是一个很好的信息路由约束；如果目标是诱导更适合 SAE 解析的 monosemantic representation，最好进一步配合 FFN 稀疏化、正交约束或 SAE-inspired regularization。
#### Entmax Attention

Entmax Attention 暂时不进入第一阶段主实验，但应保留为第二阶段候选对照组。它的价值在于提供一种介于 dense softmax 和 hard Top-K 之间的 soft sparse routing。

Entmax 定义为：

$$
\mathrm{entmax}_{\alpha}(z)
=
\arg\max_{p\in\Delta}
p^\top z + H_\alpha(p)
$$

其中 $\Delta$ 是概率 simplex，$H_\alpha$ 是 Tsallis entropy。特殊情况：

$$
\alpha=1 \Rightarrow \mathrm{softmax},\quad
\alpha=2 \Rightarrow \mathrm{sparsemax}
$$

常用的 $\alpha=1.5$ 可以产生 exact zero，同时比 hard Top-K 更平滑：

$$
p_i=[(\alpha-1)z_i-\tau]_+^{1/(\alpha-1)}
$$

用于 attention 时：

$$
A=\mathrm{entmax}_{\alpha}\left(\frac{QK^\top}{\sqrt{d_k}}\right),\quad
O=AV
$$

它回答的问题是：如果 Top-K 有效，那么有效性来自“稀疏路由本身”，还是来自“hard discrete top-k selection”？由于第一阶段要限制计算成本，因此先不运行 Entmax；若 Top-K 明显优于 baseline，再加入 Entmax 作为 soft sparse routing 对照。

### FFN 的修改
#### Grouped FFN with Limited Mixing

标准 FFN 为：

$$
\mathrm{FFN}(x)=W_2\sigma(W_1x+b_1)+b_2
$$

可以把 $W_1$ 看成 feature detector，把 $W_2$ 看成 feature writer：

$$
h=\sigma(W_1x),\quad y=W_2h
$$

Grouped FFN 将 hidden dimension 分成 $G$ 个 group，每组独立进行 feature transformation。设：

$$
x=[x^{(1)},x^{(2)},\ldots,x^{(G)}]
$$

则完全 grouped FFN 为：

$$
h^{(g)}=\sigma(W_1^{(g)}x^{(g)}+b_1^{(g)})
$$

$$
y^{(g)}=W_2^{(g)}h^{(g)}+b_2^{(g)}
$$

整体权重矩阵近似为 block-diagonal：

$$
W_1^{block}=
\begin{bmatrix}
W_1^{(1)} & 0 & \cdots & 0\\
0 & W_1^{(2)} & \cdots & 0\\
\cdots & \cdots & \ddots & \cdots\\
0 & 0 & \cdots & W_1^{(G)}
\end{bmatrix}
$$

完全独立分组的问题是 group 之间无法交流，可能损害性能。因此第一阶段更推荐 `Grouped FFN with Limited Mixing`，即在 block FFN 外加入一个低秩或小比例的跨组混合项：

$$
y=
W_2^{block}\sigma(W_1^{block}x)
+
\alpha U_2\sigma(U_1x)
$$

其中 $W^{block}$ 负责组内特征形成，$U_1,U_2$ 是低秩或窄宽度 mixing branch，$\alpha$ 控制跨组信息交流强度。

也可以写成更一般的形式：

$$
\mathrm{FFN}_{group+mix}(x)
=
\mathrm{FFN}_{block}(x)
+
\alpha \mathrm{FFN}_{mix}(x)
$$

设计动机：

1. block structure 给 feature subspace 人为加入模块边界；
2. limited mixing 避免完全分组造成性能崩塌；
3. 如果 SAE 在 grouped FFN 模型上得到更少 polysemantic feature、更少 feature duplication，说明 FFN 模块化可能有助于形成更可解析表示；
4. group-wise SAE 可以进一步检查不同 group 是否自然承担不同语义功能。

建议控制变量：

- group 数 $G$ 固定为小值，例如 $G=4$ 或 $G=8$；
- active parameter count 尽量与 baseline FFN 匹配；
- mixing branch 宽度控制在 FFN hidden width 的较小比例，例如 $10\%-25\%$；
- 只改 FFN，不同时改 attention 和 loss。

#### Sparse FFN

Sparse FFN 的目标是直接让 FFN hidden activation 更稀疏。标准 FFN hidden activation 为：

$$
h=\sigma(W_1x+b_1)
$$

普通 FFN 输出为：

$$
y=W_2h+b_2
$$

Sparse FFN 可以采用两种最小实现。

第一种是 Top-K hidden activation：

$$
I=\mathrm{TopK}_m(h_m,k)
$$

$$
\tilde{h}_m=
\begin{cases}
h_m, & m\in I\\
0, & m\notin I
\end{cases}
$$

$$
y=W_2\tilde{h}+b_2
$$

第二种是 threshold sparse activation：

$$
\tilde{h}_m=h_m\cdot \mathbf{1}[h_m>\tau]
$$

设计动机：

1. SAE 事后学习的是稀疏 feature code，而 Sparse FFN 是在原模型内部直接施加稀疏 activation 结构；
2. 如果 FFN activation 本身更稀疏，residual stream 中写入的 feature mixture 可能更少；
3. 稀疏 FFN 可以检验“模型内部激活稀疏性”是否真的会转化为“SAE feature 单义性”；
4. 它比 MoE 更简单，不引入 router、expert balancing 等额外变量。

需要注意：Sparse FFN 不等于 monosemantic FFN。它只是减少同时激活的 hidden units，模型仍可能把多个语义功能压进同一个 hidden unit 或同一组 sparse features。因此必须用 SAE 指标验证，而不能只看 FFN activation 的 L0。

建议控制变量：

- Top-K hidden activation 的 $k$ 需要让 FFN active ratio 与 baseline 的有效激活密度相近，避免过度损害 LM loss；
- 若使用 threshold，最好用 percentile threshold 或可学习 threshold，而不是固定绝对值；
- Sparse FFN 只改 FFN activation，不额外加入 L1 loss，否则会和 Loss 实验组混淆。

### Loss 的修改
#### LM + L1 Activation Sparsity

标准语言模型训练目标为：

$$
L_{LM}=-\sum_t \log p(x_t|x_{<t})
$$

该目标只要求模型提高 next-token prediction，不显式要求内部表示稀疏、单义、正交、层级或因果。因此第一阶段加入一个最小的稀疏正则项：

$$
L=L_{LM}+\lambda L_{sparse}
$$

其中：

$$
L_{sparse}=\frac{1}{BT}\sum_{b=1}^{B}\sum_{t=1}^{T}\|h_{b,t}\|_1
$$

$h_{b,t}$ 可以选择 FFN hidden activation，也可以选择某一层 residual projection。第一阶段建议优先加在 FFN hidden activation 上：

$$
h_{b,t}^{l}=\sigma(W_1^l x_{b,t}^l+b_1^l)
$$

$$
L_{sparse}=\frac{1}{LBT}\sum_{l,b,t}\|h_{b,t}^{l}\|_1
$$

设计动机：

1. L1 sparsity 是最直接、最便宜的 feature-space pressure；
2. 它和 SAE 的稀疏目标形式相近，但作用在原模型训练阶段；
3. 如果 L1 组的 SAE feature 更单义，说明“训练时稀疏压力”可能比单纯事后 SAE 更有效；
4. 它不需要额外标签、taxonomy 或 causal data，适合第一阶段低成本筛选。

需要注意：L1 loss 可能让模型整体容量下降，导致 validation loss 变差。因此不能只比较 SAE 指标，还必须报告 LM 性能代价：

$$
\Delta L_{LM}=L_{LM}^{variant}-L_{LM}^{baseline}
$$

更合理的比较方式是看单位 LM 代价换来的 SAE 收益：

$$
\frac{\Delta S_{SAE}}{\Delta L_{LM}}
$$

其中 $S_{SAE}$ 可以综合 reconstruction loss、L0、dead feature rate、interpretability score、polysemanticity 和 ablation locality。

第一阶段暂时不加入 orthogonality / hierarchy / causal losses。原因是 L1 已经足够回答“稀疏压力是否有用”；如果 L1 有效但出现 feature duplication，再在第二阶段加入 decorrelation 或 orthogonality loss。
