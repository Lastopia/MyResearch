# FFN Concept Subspace Bus V2：实验设计

## 结论先行

| 预设 | 用途 | runs | 是否用于论文结论 |
|---|---|---:|---|
| `small` | CPU 形状、梯度、因果 smoke | 1 | 否 |
| `medium` | 单 seed、38M 级止损 pilot | 7 | 仅作 pilot |
| `large` | 最小三 seed 正式矩阵 | 27 | 是 |

先跑 `medium`。如果概念 attention 没有超过仅限 token 自身的投影对照，或代价超过门槛，不运行 `large`。

## 1. 方法组

| 方法 | 唯一变化 | 回答的问题 |
|---|---|---|
| `standard` | 标准 Transformer | 原始性能 |
| `parameter_matched` | 只增大标准 FFN 到近似同参数量 | 收益是否只是参数增加 |
| `concept_aux` | 普通残差 + 概念 probe | 只加监督是否已经足够 |
| `concept_projector` | 与 V2 同参数、同 attention 算子，但只允许 token 读取自身 | 概念子空间本身是否有效 |
| `concept_bus_v2` | 将同一算子改为无旁路 causal 跨-token attention | 跨 token 概念通信是否真有增益 |

## 2. `medium`：7-run 止损实验

| 阶段 | 数据 | 方法 | seed | runs |
|---|---|---|---|---:|
| 概念与因果 | DualTag 国家×颜色 | 全部 5 方法 | 11 | 5 |
| 语言性能与成本 | TinyStories | standard / V2 | 11 | 2 |

`medium` 只回答五个问题：任务性能、概念可读性、反事实可控性、attention 增量价值、真实成本。CLUTRR 留到结构通过 pilot 后再跑。

## 3. `large`：27-run 正式矩阵

| 阶段 | 数据 | 方法 | seeds | runs |
|---|---|---|---|---:|
| 并列概念确认 | DualTag，模板外测试 | standard / matched / projector / V2 | 11、22、33 | 12 |
| 关系组合 | CLUTRR | standard / V2 | 11、22、33 | 6 |
| 通用语言建模 | FineWeb-Edu；WikiText-103 外测 | standard / matched / V2 | 11、22、33 | 9 |

合计：`12 + 6 + 9 = 27 runs`。

## 4. 数据量与训练量

| 任务 | 训练 | 验证/测试 | 训练设置 |
|---|---:|---:|---|
| DualTag | 200,000 条 | 20,000 / 20,000 条 | 6,000 steps，global batch 128，长度 256 |
| CLUTRR | 8,094 条 | 2,000；链长 2–6 各最多 2,000 | 3,000 steps，global batch 128 |
| TinyStories pilot | 1 亿 token | 固定 1,024 条 validation 序列 | 长度 256，global batch 64 |
| FineWeb-Edu formal | 10 亿 token | 1,000 万 token；WikiText-103 | 长度 512，global batch 64 |

DualTag 数据生成 seed 固定为 `20260806`；训练 seeds 为 `11/22/33`。同一任务的所有方法读取同一数据切分。

## 5. 控制变量

| 固定项 | 统一设置 |
|---|---|
| 主体架构 | decoder-only，pre-norm RMSNorm |
| 位置编码 | RoPE，$\theta=10000$ |
| 激活 | GELU |
| 原始 attention | 全部保留、严格 causal |
| 优化器 | AdamW，$\beta=(0.9,0.95)$，gradient clip 1.0 |
| 正式 LM | 12 层，$d=768$，$d_{ff}=3072$，12 heads，约 124M |
| V2 | 最后一层；2 个并列槽；槽宽 64；概念写回维度 $r=48$ |
| 预算 | 同任务内 token/step、global batch、学习率日程、验证频率一致 |

参数匹配组只改变 FFN 宽度。自适应显存调度只能改变 micro-batch 与梯度累积，global batch 不变。

## 6. 指标

| 证据类别 | 主指标 |
|---|---|
| 任务 | exact accuracy、CLUTRR 各链长 accuracy、LM loss/perplexity |
| 概念 | macro-F1、mAP、未知概念 AUROC、同标签稳定性 |
| 因果 | zero-bus drop、单组置零、sibling swap 成功率、跨组副作用 |
| attention 增益 | V2 与 projector 的配对差值 |
| 成本 | 参数、MAC、tokens/s、训练时间、峰值显存 |

验证 `loss` 只含任务交叉熵；辅助概念、反事实、正交损失只记录在训练日志，不能混进基线比较。

## 7. 预注册门槛

| 条件 | 通过线 |
|---|---:|
| V2 相对 matched 的 DualTag 差距 | ≤ 2 个百分点 |
| V2 / matched 的 LM perplexity | ≤ 1.02 |
| V2 / matched 的时间与显存 | 各 ≤ 1.25 |
| 国家、颜色 swap 成功率 | 各 ≥ 0.70 |
| 两种 swap 的跨组副作用 | 各 ≤ 0.05 |
| zero-bus exact drop | ≥ 0.05 |
| V2 对 projector 的通信收益 | 三 seed 方向一致且有实际量级 |

三个 seed 报告逐 seed 原始值、均值、标准差、置信区间和配对差值。只要性能、因果参与、attention 增益、成本任一核心门槛明显失败，就停止扩展概念 DAG。

## 8. 执行

```bash
cd RE3
python main.py --size small
python main.py --size medium
# medium 通过后才执行：
python main.py --size large
python main.py report
```
