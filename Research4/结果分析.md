# RE4 四轮实验结果与迭代分析

## 一页结论

| 判断对象 | 当前结论 | 证据强度 |
|---|---|---|
| 完整 DAG 概念总线 | **不保留**：写回参与了计算，但 DAG 边几乎不起作用，槽位高度趋同且副作用大 | 低：smoke、单 seed、无同轮标准基线 |
| Concept Bus Lite | **失败**：任务性能下降，置零总线无影响，反事实干预近乎无效 | 中低：单 seed pilot，但多个任务方向一致 |
| Concept Bus V2 的额外 causal attention | **不保留**：公平复核中比同参数 Projector 低 `11.27pp` | 中：同数据、同微批、同参数，但仍只有一个 seed 和合成任务 |
| FFN Concept Projector | **值得继续验证**：公平复核中比 Standard 高 `5.635pp`，且干预方向基本正确 | 中：当前最强信号，但尚不能作为论文结论 |
| 整体研究方向 | **不是完全失败，而是原“概念 Attention/DAG”路线失败**；研究问题应收缩到 FFN 中间概念接口和独立写回 | 条件性结论 |

> 最终教训：上下文继续交给标准 Attention；FFN 内保留少量、可命名、可干预的概念组。不要恢复第二套 Attention，也不要在证据不足时继续扩展 DAG。

## 1. 证据使用规则

| 目录 | 性质 | 能否直接用于论文 |
|---|---|---|

四轮全部只有 seed 11。跨轮代码指纹和部分运行配置不同，因此下文是**研究迭代记录**，不是把四轮数值当成同一实验的学习曲线。

## 2. 迭代总览

| 轮次 | 当时假设 | 主要设计 | 关键发现 | 为什么进入下一轮 |
|---:|---|---|---|---|
| 1：`output` | 固定锚点、DAG 和概念总线可形成可追踪中介 | Full-DAG、概念节点、边路由、独立写回 | 任务和置零指标看似很好，但槽位余弦 `0.990`、打乱 DAG 仅掉 `1.17pp`、跨概念副作用约 `25pp` | 结构过重，无法确认 DAG 是否真有价值；收缩为 Bus-Lite |
| 2：`output2` | 少量概念槽和轻量通信足以保留可审计性 | Concept Bus Lite；另有 Standard、参数匹配和 Concept-Aux | DualTag 比 Standard 低 `11.295pp`；置零总线掉点 `0`；颜色反事实成功率 `0` | 轻量分支被模型绕过；需让概念通路真实写回并改善梯度流 |
| 3：`output3` | 专属残差写回、平衡损失和概念 Attention 能迫使分支参与 | Projector 作为无跨 token 对照；V2 加独立 causal attention | V2 已参与计算，但比 Projector 低 `12.035pp`；Projector 接近 Standard | Projector 与 Aux 使用 `4×32`，Standard/V2 使用 `64×2`；SmoothMax 对微批非线性，必须公平复核 |
| 4：`output4` | 只改变“是否跨 token 通信”，即可判断概念 Attention 的增量价值 | Standard、同参数 Projector、V2；统一数据、微批、验证和选点 | Projector `76.13%` 最好；V2 `64.86%`，比 Projector 低 `11.27pp` | 额外概念 Attention 被否定；保留简单 FFN 概念接口继续研究 |

## 3. 第一轮：Full-DAG 原型

`output` 中汇总器混合了不同配置，不能使用目录总均值。下表选用最后一组稳定的 300 步代表记录 `8668a5155d2d`；随后两个 5 步结果只用于检查新 smoke 路径。

| 指标 | 结果 | 解读 |
|---|---:|---|
| Exact accuracy | 84.375% | 小样本上能够拟合任务 |
| Concept macro-F1 | 75.504% | 概念可预测，但不等于纯净或忠实 |
| 置零总线 exact drop | 64.063pp | 总线/写回路径确实参与预测 |
| 打乱 DAG exact drop | 1.172pp | **DAG 边几乎没有提供关键计算** |
| 槽位余弦相似度 | 0.990 | 槽位严重趋同，概念分工可疑 |
| COUNTRY→COLOR 副作用 | 26.172pp | 干预不特异 |
| COLOR→COUNTRY 副作用 | 25.000pp | 干预不特异 |
| Unknown AUROC | 0.501 | 约等于随机 |

| 本轮得到的教训 | 结论 |
|---|---|
| 写回置零会显著掉点 | 结构参与计算 |
| 打乱 DAG 几乎不掉点 | 不能声称模型使用了 DAG 推理 |
| 槽位高度相似、干预互相影响 | “参与计算”不等于“概念独立、可审计” |
| 只有 256 个测试样本、一个 seed、无公平 Standard | 只能算可行性原型 |

## 4. 第二轮：Concept Bus Lite

### 4.1 DualTag

| 模型 | Exact | Concept F1 | 置零总线 drop | COUNTRY CF | COLOR CF |
|---|---:|---:|---:|---:|---:|
| Standard | 69.870% | — | — | — | — |
| Parameter-matched | 72.170% | — | — | — | — |
| Concept-Aux | 65.815% | 78.708% | — | — | — |
| Concept Bus Lite | **58.575%** | **64.172%** | **0.000pp** | **3.030%** | **0.000%** |

Bus-Lite 相对 Standard 低 `11.295pp`，相对参数匹配基线低 `13.595pp`。最关键的是置零总线完全不掉点，说明模型没有依赖这条结构化通路。

### 4.2 CLUTRR 与 TinyStories

| 任务 | Standard | Bus-Lite | 结论 |
|---|---:|---:|---|
| CLUTRR overall accuracy | 26.384% | 26.221% | 无增益 |
| CLUTRR length 6 | 5.607% | 1.869% | 长链更差 |
| TinyStories validation PPL | 1.7263 | 1.7280 | 基本相同，Bus-Lite 略差 |
| TinyStories 训练时间 | 450.7s | 616.5s | Bus-Lite `+36.8%` |
| TinyStories 峰值显存 | 5.25 GiB | 6.63 GiB | Bus-Lite `+26.3%` |

**本轮结论：**更慢、更占显存，却没有语言性能、关系推理或因果审计收益。于是第三轮不再允许概念分支只是可选旁路。

## 5. 第三轮：Projector 与 Concept Bus V2

V2 让概念通路写入专属残差子空间；Projector 保留相同投影和写回，但不允许跨 token 通信，用于隔离额外 Attention 的贡献。

### 5.1 DualTag 结果

| 模型 | Exact | Concept F1 | 置零分支 drop | COUNTRY CF | COLOR CF |
|---|---:|---:|---:|---:|---:|
| Standard | 75.880% | — | — | — | — |
| Parameter-matched | 70.420% | — | — | — | — |
| Concept-Aux | 68.015% | 80.907% | — | — | — |
| Projector | 75.750% | 81.188% | 15.300pp | 100.000% | 77.004% |
| V2 | **63.715%** | **74.735%** | 16.950pp | 96.364% | 100.000% |

这轮第一次说明：V2 分支不再被完全绕过，反事实干预也能改变目标。但 V2 相对 Projector 低 `12.035pp`，概念 Attention 没有带来任务收益。

### 5.2 TinyStories 与公平性问题

| 指标 | Standard | V2 | 差异 |
|---|---:|---:|---:|
| Validation PPL | 1.7291 | 1.7312 | `+0.12%` |
| 训练时间 | 451.0s | 462.6s | `+2.58%` |
| 峰值显存 | 5.25 GiB | 5.33 GiB | `+1.43%` |

| 方法 | micro-batch | 梯度累积 |
|---|---:|---:|
| Standard / Parameter-matched / V2 | 64 | 2 |
| Projector / Concept-Aux | 4 | 32 |

SmoothMax 在样本维度上是非线性的，因此 `4×32` 与 `64×2` 不只是运行速度不同，优化目标也不完全等价。Projector 的 3388.7 秒训练时间也主要反映极小微批调度，不能解释为结构成本。由此产生第四轮公平复核。

## 6. 第四轮：公平三模型复核

固定条件：同一数据和顺序、seed 11、38M 级模型、6000 步、`micro-batch=64`、梯度累积 2、完整 20,000 条验证集、按纯任务验证损失选择 best checkpoint。

### 6.1 任务与概念结果

| 模型 | Exact | COUNTRY | COLOR | Concept F1 | Unknown AUROC | Best step |
|---|---:|---:|---:|---:|---:|---:|
| Standard | 70.495% | 80.085% | **88.780%** | — | — | 500 |
| Projector | **76.130%** | **86.585%** | 87.075% | **80.598%** | 0.589 | 2000 |
| V2 | 64.860% | 74.970% | 87.850% | 74.962% | 0.483 | 2000 |

| 核心差异 | 数值 |
|---|---:|
| Projector − Standard | **+5.635pp** |
| V2 − Standard | **−5.635pp** |
| V2 − Projector | **−11.270pp** |
| V2 Concept F1 − Projector | **−5.636pp** |

### 6.2 因果审计

| 指标 | Projector | V2 | 更好者 |
|---|---:|---:|---|
| 置零分支 exact drop | 8.600pp | 6.900pp | Projector |
| COUNTRY CF success | 96.162% | 90.909% | Projector |
| COLOR CF success | 100.000% | 100.000% | 持平 |
| COUNTRY CF→COLOR 副作用 | 0.200pp | 1.100pp | Projector |
| COLOR CF→COUNTRY 副作用 | 0.000pp | 0.650pp | Projector |

两种概念结构都参与了计算，但 Projector 的任务性能、概念质量、必要性和干预特异性整体更好。V2 的额外 Attention 没有换来可见收益。

### 6.3 计算成本

| 模型 | 参数 | MAC/样本 | 训练时间 | 吞吐 | 峰值显存 |
|---|---:|---:|---:|---:|---:|
| Standard | 37.814M | 10.469B | 191.9s | 4002.6/s | 1.36 GiB |
| Projector | 38.028M | 10.524B | 236.9s | 3241.2/s | 1.38 GiB |
| V2 | 38.028M | 10.545B | 226.6s | 3388.7/s | 1.38 GiB |

| 相对 Standard | 参数 | 理论 MAC | 实测时间 | 吞吐 |
|---|---:|---:|---:|---:|
| Projector | +0.57% | +0.52% | +23.5% | −19.0% |
| V2 | +0.57% | +0.72% | +18.1% | −15.3% |

理论成本很小，但当前 Python/PyTorch 研究实现的实测吞吐损失明显。V2 比 Projector 只多约 `0.20%` MAC，却损失 `11.27pp` Exact，因此失败原因更像表示与优化干扰，而不是单纯算力不足。

## 7. 最终结果应该怎样表述

### 可以说

| 可支持结论 | 依据 |
|---|---|
| 原 Full-DAG 中真正重要的是写回，不是 DAG 边 | 置零总线掉 64.06pp，打乱 DAG 只掉 1.17pp |
| Bus-Lite 被普通路径绕过 | 置零掉点为 0，反事实成功率近 0 |
| 强化写回后可以让概念分支参与计算 | Projector/V2 置零均掉点，槽位置换能改变目标 |
| 当前额外概念 Attention 是负贡献 | 公平同参数比较中 V2 比 Projector 低 11.27pp |
| 简单 FFN Projector 值得进一步验证 | 单 seed 公平复核中同时提高 Exact，并具有较好的干预特异性 |

### 不能说

| 尚不能支持的结论 | 缺少什么 |
|---|---|
| Projector 普遍优于标准 Transformer | 三个以上 seed、置信区间、不同数据集 |
| FFN 是概念接口的最佳位置 | 残差位置、输出瓶颈和同预算 FFN 接口的受控比较 |
| 概念槽已经纯净、完整 | 冻结后泄漏 probe、随机标签、概念完整性评估 |
| 能应用于真实语言模型 | CEBaB 等真实反事实数据和正式 LM 结果 |
| 能低成本持续扩展概念 | 冻结旧槽后增加新槽的顺序学习实验 |

## 8. 从 RE4 继承到新实验的内容

| 保留 | 删除/停止 |
|---|---|
| 标准 causal Attention | 第二套概念 Attention |
| FFN 中间概念投影 | 完整 DAG 和关系边 |
| 并列的 COUNTRY/COLOR 概念组 | 多个相互竞争的高层标签 |
| 独立、可干预的加性写回 | 无写回的辅助 probe 作为主方法 |
| 置零、保留、槽位置换、副作用测试 | 只用概念 F1 宣称可解释性 |
| 参数/MAC/吞吐/显存公平统计 | 不同微批次下直接比较 SmoothMax 模型 |

下一阶段应执行 `proposal.md` 中的 GFCI 筛选：比较 Standard、Projector、Residual-GFCI、Scalar-GFCI、Vector-GFCI 和 FreeMix。只有在三 seed 与 CEBaB 上同时保持性能和因果特异性，才能进入论文级结论。
