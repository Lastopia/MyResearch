## 1. 研究故事

我们要的高层概念必须同时满足两点：它已经吸收上下文，而且仍位于较易分解、可干预的 FFN 中间空间。旧版虽加入概念分支，却允许普通 FFN、门控和 attention 内残差绕过它；实验中 `zero-bus` 几乎无影响，证明“看得懂”不等于“参与计算”。

V2 因而只解决一个问题：

> 从完整 FFN 中间激活形成国家、颜色等并列概念槽；让跨 token 信息必须经过额外 causal attention；再让概念通过一个小而独占的 FFN 写回子空间产生可测因果作用。

不再同时追求动态 DAG、Top-k 路由、自动扩容和大规模概念体系。

## 2. 数学结构

原始 token attention 保留：

$$
H^{ctx}=H+\operatorname{CausalAttention}(\operatorname{Norm}(H))
$$

完整 FFN 激活：

$$
U=\phi(W_{up}\operatorname{Norm}(H^{ctx}))
\in\mathbb{R}^{B\times T\times d_{ff}}
$$

国家、颜色是两个并列低秩投影，而非互相竞争的标签：

$$
S_k=U P_k,\qquad k\in\{\text{country},\text{color}\}
$$

V2 只读取 attention 输出，不保留 $S_k$ 到读出的直接残差旁路：

$$
A_k=\operatorname{CausalAttention}_k(\operatorname{Norm}(S_k))
$$

两个概念组在序列与 K/V 状态上互不读取，但主版本共享 QKV 参数，并把组维并入 batch 一次计算，以避免两个小 attention kernel 的额外调度成本；组专属 QKV 可作为后续消融，不属于当前主张。

组内概念独立 sigmoid 激活：

$$
p^{country}=\sigma(W_cA_{country}),\qquad
p^{color}=\sigma(W_aA_{color})
$$

令 $r=0.0625d$。普通 FFN 只能写前 $d-r$ 个坐标，概念只能写后 $r$ 个坐标：

$$
\Delta H=
\operatorname{concat}
\left(W_{private}U,\ \sum_i p_i c_i\right)
$$

这不是整个残差流的绝对瓶颈，但消除了同一 FFN 更新内部最直接的写回旁路。

## 3. 训练约束

| 约束 | 解决的问题 |
|---|---|
| 概念 BCE | 槽位是否表达指定概念 |
| sibling swap 反事实 | 交换法国/英国或红/蓝后，目标输出必须按预期改变 |
| off-target 保持 | 交换国家时颜色不变，反之亦然 |
| 投影子空间正交 | 降低国家与颜色投影重合 |
| smooth-max 平衡 | 防止只优化最容易的一项 |

不用简单乘法、除法或损失倒数。先用各自 EMA 消除量纲，再以平滑最大值强调当前最弱目标：

$$
\widehat L_i=\frac{L_i}{\operatorname{EMA}(L_i)+\epsilon}
$$

$$
L_{bal}=s_{task}\tau\log\left(\frac{1}{N}\sum_i
\exp\left(\frac{\widehat L_i}{\tau}\right)\right)
$$

其中 $s_{task}=\operatorname{EMA}(L_{task})+\epsilon$，用于把平衡结果恢复到任务 loss 的量纲；只有任务目标时，结果严格退化为原始任务交叉熵。

$$
L=L_{bal}+\lambda_oL_{orth}
$$

验证与论文比较只使用纯任务损失，不混入辅助项。

## 4. 可审计性

| 证据 | “可读”还是“参与计算” |
|---|---|
| macro-F1 / mAP / AUROC | 可读 |
| 同标签稳定性、跨 seed 对齐 | 可读 |
| zero-bus / 单组置零 | 必要性 |
| 只保留某组 | 充分性 |
| sibling swap 成功率 | 定向可控性 |
| 另一标签变化率 | 干预特异性 |
| projector 与 V2 差异 | 额外 attention 的独立价值 |

成功必须同时满足可读性、因果参与、任务性能和成本四类证据。

## 5. 新颖性边界与风险

Concept Bottleneck、latent bottleneck、axial attention、共享工作空间和可干预表示均已有工作。因此只能主张组合创新，不能主张这些组件本身原创。

| 主要风险 | 当前处理 | 仍可能失败之处 |
|---|---|---|
| attention 被绕过 | 去掉概念 attention 内部残差 | 主残差流仍可完成任务 |
| 概念监督压制任务 | EMA 归一化 smooth-max | 多目标梯度仍可能冲突 |
| 标签互相覆盖 | 国家/颜色独立槽与 sigmoid | 真实概念边界可能不正交 |
| 结构代价不值 | 只在最后一层、两个槽、$r=6.25\%d$ | 小算子可能降低 GPU 利用率 |
| 人工标签不泛化 | 未知概念节点与模板外测试 | 合成标签可能高估真实可解释性 |

## 6. 止损线

| 条件 | 门槛 |
|---|---:|
| V2 相对 parameter-matched 的任务差距 | 不超过 2 个百分点 |
| LM perplexity 恶化 | 不超过 2% |
| 训练时间、峰值显存 | 各不超过 `1.25×` |
| 国家/颜色 swap 成功率 | 各至少 70% |
| swap 跨组副作用 | 各不超过 5% |
| zero-bus exact drop | 至少 5 个百分点 |
| V2 相对 projector | 必须出现可重复的通信收益 |

若 V2 不能同时通过性能、因果和成本门槛，应宣布该结构路线失败，而不是继续堆叠 DAG 或更多正则项。
