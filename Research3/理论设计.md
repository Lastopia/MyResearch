# 理论设计

## 1. 研究主题

本文研究长上下文 Transformer 中的两个位置偏置问题：

1. **固定的跨头距离尺度**：ALiBi 为各 attention head 预先指定几何级数斜率，可能使不同上下文长度下的各头 attention distance 保持近似固定比例，限制模型按内容重新分配局部与全局注意力。
2. **单调距离惩罚**：ALiBi 与 CABLE 都使位置偏置随距离单调减小。远处但与当前 query 高度相关的 key 必须克服越来越大的位置惩罚，可能不利于远程检索和跨段推理。

需要区分：

- 单调的是**位置偏置**，不一定是最终 attention；内容项 \(q_i k_j^\top\) 仍可使远端 token 获得较高权重。
- attention distance 比例固定是待验证的经验现象，不预设它一定降低性能；必须通过控制实验建立它与远程任务表现的关系。

## 2. 相关模型与论文

### 2.1 RoPE

- 论文：[RoFormer: Enhanced Transformer with Rotary Position Embedding](https://arxiv.org/abs/2104.09864)
- 长度扩展参考：[Extending Context Window of Large Language Models via Positional Interpolation](https://arxiv.org/abs/2306.15595)
- 核心机制：对 query 和 key 施加随位置变化的旋转，使其点积包含相对位置信息。
- 优点：
  - 位置信息与 query-key 内容交互，不强制所有 key 接受线性、单调的距离惩罚。
  - 训练长度内表现较强，且已有以 Position Interpolation 为代表的成熟扩展路线。
  - 是当前工业模型常用的位置编码，可作为实际参考基线。
- 缺点：
  - 原生 RoPE 在超过训练长度时会遇到未见过的旋转角度，零样本长度外推可能迅速退化。
  - 长上下文性能通常依赖插值、频率缩放或继续训练，不能把“原生 RoPE”和“适配后的 RoPE”混为一谈。
- 本文用途：作为非线性、非 ALiBi 式距离先验的主要参考；实验同时报告原生 RoPE 与 RoPE-PI 推理结果。

### 2.2 ALiBi

- 论文：[Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation](https://openreview.net/forum?id=R8sQPpGCv0)
- 核心机制：

\[
\ell_{ij}^{h}
=
\frac{q_i^h{k_j^h}^{\top}}{\sqrt d}
-m_h(i-j),
\qquad j\le i
\]

其中 \(m_h\) 是训练前固定的 head-specific slope。原论文对多个头使用几何数列斜率。

- 优点：
  - 实现简单，不需要位置 embedding 参数。
  - 原生零样本长度外推通常比未经适配的 RoPE 稳定。
  - 近因偏置有利于语言模型的局部依赖建模。
- 缺点：
  - 各头斜率固定且近似等比，无法随输入内容和上下文长度调整。
  - 位置惩罚严格单调并随距离线性增长，容易形成软滑动窗口。
  - 超长 PPL 稳定可能主要反映局部建模，而不代表真正使用了远程信息。
  - 充分训练后，零样本外推范围可能明显收缩。
- 本文用途：核心被改进对象，也是检验 attention distance 固定比例现象的主要模型。

### 2.3 CABLE 与 K-CABLE

- 论文：[Context-aware Biases for Length Extrapolation](https://aclanthology.org/2025.emnlp-main.1545/)
- 官方代码：[AlgonetLabs/Cable](https://github.com/AlgonetLabs/Cable)
- 核心机制：

\[
c_t^h=\operatorname{ReLU}(x_t^\top w_c^h)\ge0,
\qquad
S_i^h=\sum_{t\le i}c_t^h
\]

\[
g_i^h=\operatorname{Softplus}(x_i^\top w_s^h)>0,
\qquad
b_{ij}^h=-g_i^h(S_i^h-S_j^h)
\]

CABLE 将 ALiBi 的固定斜率改为依赖 token、head、layer 和上下文的累计距离。K-CABLE 使用
\(b_{ij}^h=-g_i^h\log(1+(S_i^h-S_j^h)^2)\)，即先对距离应用慢增长 kernel，再乘 query 权重，以减弱滑动窗口效应。

- 优点：
  - 打破 ALiBi 固定的几何 head slope，各头可以按输入动态改变有效距离。
  - 保留加性相对位置偏置和较好的长度外推性质。
  - 论文在 PPL 和长上下文检索上均优于 ALiBi。
- 缺点：
  - 因 \(c_t^h\ge0\) 且 \(g_i^h>0\)，更远 key 的位置惩罚仍然不小于更近 key，单调性没有消失。
  - \(S_i-S_j=\sum_{t=j+1}^{i}c_t\) 主要描述 query-key 之间的“路径成本”；远端 key \(j\) 自身的重要性不能直接获得位置豁免。
  - K-CABLE 只让惩罚增长更慢，仍未产生内容相关的非单调偏置。
  - 论文承认超过 100K 和任意长度下的 attention 动力学仍缺少理论与实验验证。
- 本文用途：CABLE 是当前首轮的直接前身与基线；K-CABLE 只作为相关工作记录，不进入本轮四模型代码。

### 2.4 DAPE

- 论文：[DAPE: Data-Adaptive Positional Encoding for Length Extrapolation](https://proceedings.neurips.cc/paper_files/paper/2024/hash/2f050fa9f0d898e3f265d515f50ae8f9-Abstract-Conference.html)
- 官方代码：[chuanyang-Zheng/DAPE](https://github.com/chuanyang-Zheng/DAPE)
- 核心机制：

\[
A_{\mathrm{DAPE}}
=QK^\top+B+f(QK^\top,B)
\]

其中 \(B\) 是静态位置先验，\(f\) 使用跨 head MLP 同时观察 query-key 内容分数和位置偏置并输出自适应残差。DAPE 是重要相关工作，但不进入当前首轮四模型实验。

- 优点：
  - 位置修正直接依赖 query-key 内容相关性。
  - 输出不受非负累积约束，可以产生 local 与 anti-local、非单调的位置模式。
  - 是检验“自由的数据自适应 bias”是否有效的强基线。
- 缺点：
  - 对完整 attention score 矩阵增加非线性变换，训练开销和实现复杂度高于 ALiBi/CABLE。
  - bias 较自由，较难解释，也可能破坏稳定的局部先验或产生 attention sink。
  - 它证明了自适应 bias 可行，但没有专门约束“只对相关远端 token 提供豁免”。
- 本文用途：最强自适应对照，避免把已有的数据自适应思想误当作本文创新。

### 2.5 本文方法：RA-CABLE（暂定名）

RA-CABLE 表示 **Relevance-Aware CABLE**。当前首轮原型不另建低秩 Q/K，而是直接复用 attention 已经计算出的真实内容分数，让高相似度 query-key 对减弱 CABLE 的距离惩罚。

首先保留 CABLE 距离：

\[
d_{ij}^{h}
=
\sum_{t=j+1}^{i}
\operatorname{ReLU}(w_c^{h\top}x_t)
\]

CABLE 基础偏置为：

\[
b_{ij}^{h,\mathrm{CABLE}}
=
-\operatorname{Softplus}(w_g^{h\top}x_i)d_{ij}^{h}
\]

直接使用原始 attention 内容分数：

\[
\ell_{ij}^{h}
=
\frac{q_i^h{k_j^h}^{\top}}{\sqrt d}
\]

相关性门与最终偏置为：

\[
r_{ij}^{h}
=
\sigma\left(\operatorname{Softplus}(s_h)\ell_{ij}^{h}+a_h\right)
\]

\[
b_{ij}^{h,\mathrm{RA}}
=
b_{ij}^{h,\mathrm{CABLE}}(1-r_{ij}^{h})
\]

解释：

- \(r_{ij}\approx0\)：使用正常的 CABLE 局部距离惩罚。
- \(r_{ij}\approx1\)：相关 key 的距离惩罚趋近于 0，但不会由该模块直接获得正向奖励。
- 因 \(r_{ij}\) 依赖具体 query-key，相同距离可获得不同惩罚，远端相关 key 的偏置也可能高于近端无关 key。
- Sigmoid 将豁免率限制在 \([0,1]\)，轻量稀疏正则防止所有位置都被豁免。

预期优点：

- 保留 CABLE 的动态距离，同时打破严格由距离决定的 pairwise 排序。
- 比 DAPE 更明确地区分“稳定距离先验”和“语义豁免”，便于解释与消融。
- 可以从接近 CABLE 的状态初始化，降低训练不稳定风险。

主要风险：

- relevance gate 可能放大原始 \(QK^\top\) 偏差，形成正反馈。
- 某些高频或特殊 token 可能被错误地持续豁免，形成 attention sink。
- 原始 CABLE 累积距离仍可随超长序列增大；若 gate 没有识别出相关 key，远端惩罚仍然可能过强。
- 在完整 \(L\times L\) attention 上保存和处理 gate，会增加显存与逐元素计算成本。

控制措施：

- gate 初始偏向关闭，使模型从近似 CABLE 开始训练。
- 对平均豁免率加入轻量稀疏正则。
- 同时报告正确豁免率和错误豁免率，不能只展示非单调性增加。

## 3. 本文要解决的问题

现有方法存在一个未被同时解决的缺口：

- ALiBi 具有固定几何 head 尺度和严格单调线性惩罚。
- CABLE 解决了固定尺度，但仍是单调累计距离。
- DAPE 可以产生非单调模式，但缺少稳定、可解释的距离先验与豁免边界。

本文拟回答：

1. ALiBi 的各头 attention distance 相对比例是否在不同上下文长度和不同内容间保持异常稳定？
2. 这种固定比例是否与远程检索能力下降相关，而不仅是一个无害的可视化现象？
3. CABLE 是否能改变跨头距离比例，但仍因单调 bias 压制远端相关 token？
4. 在保留 CABLE 局部先验的情况下，受约束的 relevance exemption 能否提高远程信息利用，同时维持短上下文质量、长度外推稳定性和效率？

## 4. 核心假设

- **H1：固定比例假设。** ALiBi 的 head attention distance share 在长度和内容变化时，比 RoPE、CABLE 与 RA-CABLE 更稳定，并更接近几何分布。
- **H2：远程利用假设。** 当远端相关 token 与近端干扰 token 同时存在时，ALiBi/CABLE 的相关 token attention margin 和检索准确率低于允许非单调 bias 的模型。
- **H3：受约束豁免假设。** RA-CABLE 在远程检索上优于 CABLE，同时错误豁免率可控，并保持短上下文 PPL。
- **H4：非充分性假设。** 非单调比例本身不是成功标准；只有当其由语义相关性触发并带来任务提升时，才能支持本文机制。

## 5. 论文目标

本文拟提出并验证一种**具有稳定局部先验、动态 head 距离和内容相关非单调豁免的位置偏置**。最终贡献不是声称“距离偏置越弱越好”，而是证明：

> 长上下文模型需要把一般 token 的局部性先验，与少量远端关键 token 的语义访问能力分离建模。
