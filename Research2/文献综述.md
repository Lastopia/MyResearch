# 研究综述

> 研究问题：哪些 Transformer 机制修改，可能诱导模型形成更单义、更解耦、更层级化、更因果化、也更适合 SAE 解析的内部表示？

本文是一份面向研究设计的文献综述。重点不是介绍 Transformer，而是把 2017-2025 年间的注意力机制、FFN/MLP 结构、训练目标变体放在同一个问题下比较：这些机制是否只是提高效率或性能，还是也可能改变内部表征的几何、模块化、稀疏性、因果可干预性，以及 SAE 能否更容易解析这些表征。

## Executive Summary

Transformer 内部表示是否单义、层级、因果、可解耦，不只取决于模型大小和训练数据，也取决于信息如何路由、特征如何变换、训练信号奖励什么结构。

最有研究潜力的方向如下：

| Direction | Most Promising Mechanisms | Why It Matters for SAE / MI |
|---|---|---|
| Attention | Top-k / threshold / entmax / native sparse attention | 把 attention 从 dense soft routing 改为稀疏、内容依赖的信息路径，可能让 circuit path 更局部、更可干预 |
| FFN | grouped FFN, limited-mixing grouped FFN, SwiGLU, sparse FFN, MoE | FFN 更像 token-wise feature transformation；模块化或稀疏 FFN 可能比 attention 更直接改变特征形成方式 |
| Loss | L1 / L0 sparsity, orthogonality, hierarchy-aware contrastive loss, causal relation loss, bottleneck | 结构化目标可以显式奖励稀疏、去冗余、层级距离、因果方向，而不是只优化 next-token likelihood |
| SAE | post-hoc SAE, TopK SAE, JumpReLU SAE, gated SAE, transcoders, sparse feature circuits | 当前 SAE 多用于事后解析，较少用于端到端诱导模型形成更可解析表示，这是核心空白 |

核心判断：

1. **Attention 变体大多为了效率提出**，但 Top-k、threshold、entmax、NSA 这类内容依赖稀疏路由值得重新解释为 interpretability-oriented routing constraints。
2. **FFN 变体更接近表示形成机制**。FFN key-value memory、gated FFN、MoE、grouped FFN、sparse FFN 都直接作用于 token-wise feature basis，更可能影响 SAE feature quality。
3. **Loss 变体是最直接的表征塑形工具**。稀疏、正交、层级、因果目标可以作为控制变量实验中最清晰的干预。
4. **目前几乎没有系统研究把 architecture variants 与 SAE monosemanticity 放在同一个实验矩阵里比较**。这是可作为论文创新点的研究空白。

# Part I. Attention Variants

## 1. Standard Scaled Dot-Product Attention

**代表论文**：Vaswani et al., 2017, *Attention Is All You Need*  
**链接**：[arXiv](https://arxiv.org/abs/1706.03762), [NeurIPS](https://proceedings.neurips.cc/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html)  
**GitHub**：原论文无单一官方训练仓库；常用实现见 [tensor2tensor](https://github.com/tensorflow/tensor2tensor)、[fairseq](https://github.com/facebookresearch/fairseq)、[transformers](https://github.com/huggingface/transformers)。

### 核心思想

Scaled dot-product attention 通过 query、key、value 进行内容寻址：

$$
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

多头注意力：

$$
\mathrm{MHA}(X)=\mathrm{Concat}(h_1,\ldots,h_H)W^O,\quad
h_i=\mathrm{Attention}(XW_i^Q,XW_i^K,XW_i^V)
$$

Q、K、V 的角色：

- **Q / query**：当前位置要寻找什么信息。
- **K / key**：其他位置提供什么可被匹配的地址。
- **V / value**：被路由回来的内容。
- **QK 相似度**决定路由权重，**V**决定被混合的信息内容。

### Attention as Information Routing

Attention 更准确地说是 **information routing mechanism**，不是 reasoning mechanism 本身。它决定哪些 token 的信息会被复制、聚合、移动到当前残差流位置。推理能力来自多层 attention、FFN、残差流、训练目标和数据分布共同形成的电路，而不是某个 attention map 的可视化。

### 为什么 attention 不等于 reasoning

1. Attention weight 是路由权重，不是因果解释。高权重 token 不一定是输出行为的充分原因。
2. Value vector、output projection、后续 MLP、残差叠加都会改变信息含义。
3. 多头、多层之间存在 composition；单层 heatmap 容易忽略后续计算。
4. *Attention is not explanation* 争论说明 attention weight 与 causal attribution 常不一致。

### 与 representation learning 的关系

Attention 主要改变 **token-token interaction**，使某一位置的 residual representation 包含来自其他位置的信息。它对表示学习的贡献在于：

- 将局部 token 表示变为上下文条件表示。
- 形成跨 token 的 relational features。
- 在 induction heads、copy heads、name-mover heads 等电路中承担路由角色。

### 诱导潜力

| Property | Assessment |
|---|---|
| Monosemanticity | 间接。dense softmax 会混合很多来源，可能增加 superposition；稀疏 attention 可能更有利 |
| Hierarchy | 间接。多层 attention 可以组合低阶关系为高阶关系，但原始目标不显式鼓励层级 |
| Causality | 弱。causal mask 只是时间方向约束，不等于因果表征 |
| Disentanglement | 弱到中等。多头可能分工，但无显式去冗余约束 |

**控制变量版本**：标准 dense causal self-attention，same heads, same $d_{model}$, same training tokens。

### 代表机制与论文

|---|---:|---|---|---|---|

| Longformer | *Longformer: The Long-Document Transformer* | 2020 | Beltagy et al. | [arXiv](https://arxiv.org/abs/2004.05150) | [allenai/longformer](https://github.com/allenai/longformer) |

| ETC | *ETC: Encoding Long and Structured Inputs in Transformers* | 2020 | Ainslie et al. | [arXiv](https://arxiv.org/abs/2004.08483) | [google-research/google-research/tree/master/etcmodel](https://github.com/google-research/google-research/tree/master/etcmodel) |
| Sinkhorn Transformer | *Sparse Sinkhorn Attention* | 2020 | Tay et al. | [arXiv](https://arxiv.org/abs/2002.11296) | various |

### 固定稀疏 vs 动态稀疏

| Type | Examples | Pattern |
|---|---|---|
| 固定稀疏 | Sparse Transformer, Longformer, BigBird | local window, strided, global tokens, random blocks |
| 内容依赖动态稀疏 | Routing Transformer, Reformer-LSH, Sinkhorn | 根据 token embedding / hash / sorting / clustering 改变连接 |
| 混合 | BigBird, NSA | 局部 + 全局 + 随机或动态选择 |

### 数学形式

标准 attention：

$$
A=\mathrm{softmax}(S),\quad S=\frac{QK^\top}{\sqrt{d_k}}
$$

稀疏 attention 引入 mask $M$：

$$
A_{ij}=
\frac{\exp(S_{ij})\mathbf{1}[(i,j)\in M]}
{\sum_{j':(i,j')\in M}\exp(S_{ij'})}
$$

其中 $M$ 可以是固定模式，也可以由内容函数生成：

$$
M_i = \mathrm{Route}(q_i,K,X)
$$

### 是否只是为了效率？

最初目的主要是 **效率和长上下文**。Sparse Transformer、Longformer、BigBird、Reformer 等主要减少 $O(n^2)$ 成本。但从可解释性角度，稀疏 attention 也可能产生副作用：

- 更少 token 被混合，信息路径更短、更清楚。
- mask 或 routing decision 可作为 circuit graph 的候选边。
- 固定稀疏模式可能强迫局部/全局角色分离。
- 动态稀疏模式可能产生 content-based modular routing。

### 是否研究过对内部特征可解释性的影响？

结论：**很少系统研究**。已有 mechanistic interpretability 工作主要分析标准 dense attention 中的 induction heads、IOI circuit、name mover heads 等。稀疏 attention 的 MI 分析多停留在效率、长上下文、attention pattern 可视化，尚未形成与 SAE monosemanticity 直接关联的系统研究。

### SAE 结合情况

未见主流工作系统比较 Sparse Transformer vs dense Transformer 对 SAE feature interpretability 的影响。可作为明确研究空白。

### 诱导潜力

| Property | Potential |
|---|---|
| Monosemanticity | 中。减少混合可能降低 polysemantic routing，但 fixed sparse 不保证 feature sparsity |
| Hierarchy | 中。local-global sparse pattern 可天然对应局部到全局层级 |
| Causality | 低到中。可减少路径数量，便于 causal tracing，但不显式学习因果 |
| Disentanglement | 中。动态 routing 可能形成 token cluster specialization |

**控制变量版本**：Longformer-style local window + selected global tokens；BigBird local+random+global；Routing Transformer content clustering。

## 3. Top-k Attention / Threshold Attention

### 代表论文

| Mechanism | Paper | Year | Authors | Link | Code |
|---|---:|---|---|---|---|
| Top-k Attention | *Memory-efficient Transformers via Top-k Attention* | 2021 | Gupta et al. | [arXiv](https://arxiv.org/abs/2106.06899) | [HuggingFace issue/implementations vary](https://github.com/huggingface/transformers) |
| Dynamic Sparse Attention | dynamic sparse attention family | 2020-2025 | multiple | examples include routing/LSH/learned sparse | various |
| Native Sparse Attention | *Native Sparse Attention: Hardware-Aligned and Natively Trainable Sparse Attention* | 2025 | Yuan et al. / DeepSeek-related authors | [arXiv](https://arxiv.org/abs/2502.11089) | not always official at time of writing |
| Top-p / nucleus attention | not standard training attention; mostly sampling analogy | 2019+ | Holtzman et al. for nucleus sampling | [arXiv](https://arxiv.org/abs/1904.09751) | decoding libraries |

### 核心思想

Top-k attention 保留每个 query 最相关的 $k$ 个 key：

$$
I_i = \mathrm{TopK}_j(S_{ij}, k),\quad
A_{ij} =
\begin{cases}
\frac{\exp(S_{ij})}{\sum_{j'\in I_i}\exp(S_{ij'})}, & j\in I_i\\
0, & \text{otherwise}
\end{cases}
$$

Threshold attention 保留超过阈值的边：

$$
I_i = \{j:S_{ij}>\tau_i\}
$$

阈值可以固定，也可以根据 query、层、head、sequence length 自适应。

### Top-k attention 是 content-based sparse routing 吗？

是。与 Longformer/BigBird 的固定 mask 不同，Top-k 由当前 $QK^\top$ 内容相似度决定连接边。因此它是 **content-based, query-specific, dynamic sparse routing**。

### 与 fixed sparse attention 的区别

| Aspect | Fixed Sparse | Top-k / Threshold |
|---|---|---|
| Mask 来源 | 位置规则 | 内容相似度 |
| 每个样本是否变化 | 通常不变 | 变化 |
| 可解释对象 | 结构先验 | 被选择的信息路径 |
| 风险 | 固定模式错过远距离相关 token | hard selection 训练不稳定，可能丢信息 |
| 解释潜力 | 层级/局部性较清楚 | 单个 token 的 causal path 更清楚 |

### Native Sparse Attention

NSA 采用动态层级稀疏策略，将 coarse-grained token compression 与 fine-grained token selection 结合，目标是让长上下文训练和推理都高效，同时保持性能。它代表 2025 年以后稀疏注意力的新趋势：不是把 dense attention 训练好之后近似，而是 **natively trainable sparse attention**。

### 是否可能诱导更单义、更清晰的信息路径？

可能，但尚未被充分验证：

- Top-k 把每个 query 的路由边限制在少数 key，理论上降低 value mixing。
- 被选中的边更像离散 circuit edge，适合 causal ablation。
- 若不同 head 学到稳定 Top-k pattern，可能产生 head specialization。
- 但 hard Top-k 也可能把多个功能压进同一条边，造成新的 superposition。

### 是否有人用 SAE 分析过 Top-k Attention？

截至 2025 年主流 SAE 文献主要分析 residual stream、MLP activations、attention output 或训练 transcoders，很少系统比较 Top-k attention 架构本身对 SAE features 的影响。**Top-k attention + SAE 是一个强 research gap**。

### 控制变量版本

- Top-k after causal mask，$k \in \{16, 32, 64, 128\}$。
- Threshold attention with adaptive per-query percentile threshold。
- Soft Top-k / differentiable Top-k for stability。
- Native-sparse style：compressed global context + selected fine tokens。

## 4. Entmax / Sparsemax Attention

### 代表论文

| Mechanism | Paper | Year | Authors | Link | Code |
|---|---:|---|---|---|---|
| Sparsemax | *From Softmax to Sparsemax* | 2016 | Martins & Astudillo | [arXiv](https://arxiv.org/abs/1602.02068) | [deep-spin/entmax](https://github.com/deep-spin/entmax) |
| Entmax | *Sparse Sequence-to-Sequence Models* / entmax family | 2019 | Peters et al.; Correia et al. | [arXiv](https://arxiv.org/abs/1905.05702) | [deep-spin/entmax](https://github.com/deep-spin/entmax) |
| Adaptively Sparse Transformers | *Adaptively Sparse Transformers* | 2019 | Correia et al. | [arXiv](https://arxiv.org/abs/1909.00015) | [deep-spin/entmax](https://github.com/deep-spin/entmax) |

### Softmax vs Sparsemax vs Entmax

Softmax：

$$
\mathrm{softmax}(z)_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

Sparsemax 是欧氏投影到概率 simplex：

$$
\mathrm{sparsemax}(z)=\arg\min_{p\in\Delta^{d-1}}\|p-z\|^2
$$

Entmax 是一族 Tsallis entropy-regularized mapping：

$$
\mathrm{entmax}_{\alpha}(z)=
\arg\max_{p\in\Delta^{d-1}} p^\top z + H_{\alpha}(p)
$$

其中 $\alpha=1$ 近似 softmax，$\alpha=2$ 对应 sparsemax，$\alpha=1.5$ 常用作平衡稀疏性与平滑性。

### 为什么 Entmax 可以产生稀疏概率分布

Entmax 的归一化形式允许低分元素被截断为 0：

$$
p_i = [(\alpha-1)z_i-\tau]_+^{1/(\alpha-1)}
$$

因此它不像 softmax 那样给所有 token 非零概率。

### Entmax 是否比 hard Top-k 更可微？

是。Entmax/sparsemax 的 support 变化处仍有非光滑点，但整体比 hard Top-k 更适合梯度训练。它保留了“概率分布”解释，同时产生精确零权重。

### 可解释性意义

Entmax 是一个非常适合 interpretability 控制实验的机制：

- 与 softmax 只差归一化函数，architecture change 小。
- 可产生可微稀疏 attention map。
- support size 可度量，方便比较 attention path sparsity。
- 可以测试“稀疏概率路由是否提升 SAE feature monosemanticity”。

### SAE 结合情况

未见主流 LLM SAE 工作把 entmax attention 作为模型训练变量系统研究。研究空白明确。

## 5. Linear Attention / Kernel Attention

### 代表论文

| Mechanism | Paper | Year | Authors | Link | Code |
|---|---:|---|---|---|---|
| Linear Transformer | *Transformers are RNNs* | 2020 | Katharopoulos et al. | [arXiv](https://arxiv.org/abs/2006.16236) | [idiap/fast-transformers](https://github.com/idiap/fast-transformers) |
| Performer / FAVOR+ | *Rethinking Attention with Performers* | 2020 | Choromanski et al. | [arXiv](https://arxiv.org/abs/2009.14794) | [google-research/google-research/tree/master/performer](https://github.com/google-research/google-research/tree/master/performer) |
| CosFormer | *CosFormer: Rethinking Softmax in Attention* | 2022 | Qin et al. | [arXiv](https://arxiv.org/abs/2202.08791) | various |
| RetNet | *Retentive Network* | 2023 | Sun et al. | [arXiv](https://arxiv.org/abs/2307.08621) | [microsoft/unilm](https://github.com/microsoft/unilm) |

### 核心思想

Linear attention 用 kernel feature map $\phi$ 近似或替代 softmax attention：

$$
\mathrm{Attn}(Q,K,V)_i =
\frac{\phi(q_i)^\top \sum_j \phi(k_j)v_j^\top}
{\phi(q_i)^\top \sum_j \phi(k_j)}
$$

这样可以把 $QK^\top V$ 改写为 $Q(K^\top V)$，从 $O(n^2)$ 变为 $O(n)$ 或近似线性。

### 与原始 Transformer 的区别

- 不显式保存完整 attention matrix。
- 更像 recurrent state update 或 kernel aggregation。
- 单个 token 的 attribution path 更难直接读出，因为路由被压缩到全局状态中。

### 可解释性影响

线性注意力主要为了效率。它可能不利于基于 attention edge 的 circuit tracing，因为 $i\to j$ 的 pairwise attention edge 不再显式存在。但它也可能形成更压缩的 memory state，适合研究 bottleneck 与抽象表示。

| Property | Potential |
|---|---|
| Monosemanticity | 不明确，可能因压缩增加混合 |
| Hierarchy | 中，若 recurrent state 分层设计 |
| Causality | 弱，edge-level tracing 变难 |
| Disentanglement | 低到中，需配合 loss |

## 6. Multi-Query / Grouped-Query Attention

### 代表论文

| Mechanism                   |                                                                                  Paper | Year | Authors        | Link                                                                                                         | Code / Adoption                                                  |
| --------------------------- | -------------------------------------------------------------------------------------: | ---- | -------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| Multi-Query Attention       |                            *Fast Transformer Decoding: One Write-Head is All You Need* | 2019 | Shazeer        | [arXiv](https://arxiv.org/abs/1911.02150)                                                                    | used in PaLM-like models                                         |
| Grouped-Query Attention     | *GQA: Training Generalized Multi-Query Transformer Models from Multi-Head Checkpoints* | 2023 | Ainslie et al. | [arXiv](https://arxiv.org/abs/2305.13245)                                                                    | LLaMA-style models, TGI/vLLM support                             |
| Multi-head Latent Attention |                                                                 DeepSeek-V2/V3 reports | 2024 | DeepSeek-AI    | [DeepSeek-V2 arXiv](https://arxiv.org/abs/2405.04434), [DeepSeek-V3 arXiv](https://arxiv.org/abs/2412.19437) | [DeepSeek-V3 GitHub](https://github.com/deepseek-ai/DeepSeek-V3) |
|                             |                                                                                        |      |                |                                                                                                              |                                                                  |

### 核心思想

MQA：多个 query heads 共享同一组 K/V：

$$
h_i=\mathrm{Attention}(Q_i,K_{shared},V_{shared})
$$

GQA：$H_q$ 个 query heads 被分成 $G$ 组，每组共享 K/V：

$$
h_i=\mathrm{Attention}(Q_i,K_{g(i)},V_{g(i)})
$$

MLA：把 KV cache 通过低维 latent 表示压缩，减少长上下文推理成本。

### 是否影响 head specialization？

可能。MHA 允许每个 head 独立学习 Q/K/V；MQA/GQA 共享 K/V 后：

- query heads 仍可不同，但可访问的 key-value subspace 被共享。
- 可能减少 value-side specialization。
- 可能迫使 heads 在 query projection 或 output projection 中分工。
- 对 interpretability 的影响尚未系统研究。

### LLM 应用

MQA/GQA 已广泛用于现代 LLM 以降低 KV cache。DeepSeek-V2/V3 使用 MLA；DeepSeek-V3 报告 671B total, 37B active parameters per token，并结合 DeepSeekMoE、auxiliary-loss-free load balancing、multi-token prediction。

### SAE 结合情况

未见系统比较 MHA/MQA/GQA/MLA 对 SAE feature quality 的工作。建议作为次级研究方向，因为它更多影响 inference/memory 而非直接表示稀疏性。

## 7. Attention Head Specialization / Pruning

### 代表论文

| Topic | Paper | Year | Authors | Link |
|---|---:|---|---|---|
| Head pruning | *Are Sixteen Heads Really Better than One?* | 2019 | Michel et al. | [arXiv](https://arxiv.org/abs/1905.10650) |
| Head analysis | *Analyzing Multi-Head Self-Attention* | 2019 | Voita et al. | [arXiv](https://arxiv.org/abs/1905.09418) |
| BERT attention analysis | *What Does BERT Look at?* | 2019 | Clark et al. | [arXiv](https://arxiv.org/abs/1906.04341) |

### 核心结论

Attention heads 会学习某些可命名功能，例如：

- delimiter / separator head
- positional head
- syntactic dependency head
- induction/copy head
- name mover head

但 head 级别解释粒度较粗。一个 head 可能参与多个功能，一个功能也可能由多个 head 和 MLP features 共同完成。

### Pruning 是否会增强可解释性？

Pruning 可以减少冗余 head，使部分重要 head 更突出，但不一定使剩余 head 单义。它更适合作为：

- head importance analysis
- circuit simplification
- sparsity regularization baseline

### Head sparsity 作为表示结构约束

可设计：

$$
L = L_{LM} + \lambda \sum_{l,h}\|g_{l,h}\|_1
$$

其中 $g_{l,h}$ 是 head gate。也可以使用 group lasso 或 hard-concrete gates。

### SAE 结合情况

SAE 研究通常比 head pruning 更细粒度。可以把 pruned model 和 unpruned model 都训练 SAE，比较：

- feature count / dead rate
- feature interpretability
- circuit localization
- ablation sparsity

## 8. Attention and Mechanistic Interpretability

### 代表资料

### Attention 在电路分析中的角色

在 Transformer Circuits 视角下：

- Attention head 是从源 token 到目标 token 的可学习信息路由器。
- QK circuit 决定何时路由。
- OV circuit 决定路由什么内容。

### Attention 变体是否已有可解释性分析？

1. 同等参数和训练 token 下的 dense vs sparse attention SAE 对比。
2. Top-k support 是否对应更稳定 circuit edge。
3. Entmax support size 是否预测 feature monosemanticity。
4. NSA 式动态层级稀疏是否产生更层级化表示。

# Part II. FFN Variants

## 1. Standard FFN

**代表论文**：Vaswani et al., 2017, *Attention Is All You Need*  
**链接**：[arXiv](https://arxiv.org/abs/1706.03762)

### 公式

Transformer FFN / MLP 对每个 token 独立作用：

$$
\mathrm{FFN}(x)=W_2\sigma(W_1x+b_1)+b_2
$$

通常 $W_1:\mathbb{R}^{d_{model}}\to\mathbb{R}^{d_{ff}}$，$W_2:\mathbb{R}^{d_{ff}}\to\mathbb{R}^{d_{model}}$。

### FFN 作为 feature detector

可以把 $W_1$ 的每一行视作 pattern detector：

$$
a_i=\sigma(w_i^\top x+b_i)
$$

$W_2$ 的列向量则把检测到的 feature 写回 residual stream。

### FFN 与 attention 的区别

| Component | Main Role | Operates Across Tokens? | Interpretability Unit |
|---|---|---:|---|
| Attention | routing / copying / relational binding | yes | head, QK, OV, edge |
| FFN | token-wise feature transformation | no | neuron, MLP feature, SAE latent |

FFN 往往比 attention 更像 semantic processing，因为它在每个 token 的上下文表示上进行非线性 feature expansion 和 recomposition。

### SAE 关系

大量 SAE 工作分析 residual stream 或 MLP activations。FFN 是 SAE 研究最自然的 architecture intervention target。

---

## 2. FFN as Key-Value Memory

**代表论文**：Geva et al., 2021, *Transformer Feed-Forward Layers Are Key-Value Memories*  
**链接**：[arXiv](https://arxiv.org/abs/2012.14913)

### 核心思想

FFN 可解释为 key-value memory：

$$
\mathrm{FFN}(x)=\sum_i \sigma(k_i^\top x)v_i
$$

其中：

- $k_i$ 是 $W_1$ 中的 key / pattern detector。
- $v_i$ 是 $W_2$ 中对应 value / residual updater。

### lower vs upper layer

Geva et al. 发现：

- 低层 FFN 更偏 lexical / surface pattern。
- 中高层 FFN 更偏 semantic / task / prediction-relevant pattern。
- FFN memory slot 可以对应词汇、实体、事实、关系、语义类别。

### 对 MI 的意义

该工作把 FFN 从“黑箱 MLP”转化为可分析的 memory slots，为后续 SAE/transcoder 工作铺路。但单个 neuron/key-value slot 仍常 polysemantic，SAE 试图把这些叠加特征拆成更单义方向。

## 3. Grouped FFN / Group Feed-Forward Layer

### 代表论文

| Mechanism | Paper | Year | Authors | Link |
|---|---:|---|---|---|
| Group-Transformer | *Group-Transformer: Towards a Lightweight Character-Level Language Model* | 2019 | You et al. | [OpenReview](https://openreview.net/forum?id=rkxdexBYPB) |
| GroupBERT | *GroupBERT: Enhanced Transformer Architecture with Efficient Grouped Structures* | 2021 | Qiao et al. | [OpenReview](https://openreview.net/forum?id=eYyvftCgtD) |

### Group Linear Layer

将 hidden dimension 分成 $G$ 组，每组独立线性变换：

$$
x=[x^{(1)},\ldots,x^{(G)}],\quad
y^{(g)}=W^{(g)}x^{(g)}
$$

整体矩阵是 block-diagonal：

$$
W=
\begin{bmatrix}
W^{(1)} & 0 & \cdots & 0\\
0 & W^{(2)} & \cdots & 0\\
\cdots & \cdots & \ddots & \cdots\\
0 & 0 & \cdots & W^{(G)}
\end{bmatrix}
$$

### 为什么分组

最初主要为了 **效率和参数减少**：

- 降低 FFN 参数量。
- 降低矩阵乘法成本。
- 在 character-level 或 efficient BERT 场景中提升速度。

### 为什么完全独立分组可能损害性能

完全 block-diagonal 会限制 cross-group feature composition。语言表示往往需要组合词法、句法、实体、关系、上下文等信息。如果组间完全隔离，模型可能无法形成高阶组合特征。

### Inter-group communication

常见方法：

- group shuffle / channel shuffle
- periodic dense mixing layer
- low-rank cross-group projection
- attention-style group mixing
- residual shared subspace

### 可解释性潜力

Grouped FFN 可作为 **modular feature formation constraint**：

- 每个 group 学一类 feature。
- SAE 可分别训练在 group subspace 上，检测 feature purity。
- limited mixing 可以测试“模块化 vs 组合能力”的 tradeoff。

### SAE 结合情况

尚未见主流工作系统把 grouped FFN 与 SAE monosemanticity 结合。强研究空白。

---

## 4. Grouped FFN with Limited Mixing

### 相近方向

| Mechanism | Idea |
|---|---|
| Channel shuffle | 类似 ShuffleNet，在 group convolution 后交换通道 |
| Low-rank mixing | $y=W_{block}x + UV^\top x$，用低秩项做组间通信 |
| Periodic dense mixing | 每 $m$ 层插入 dense FFN 或 dense projection |
| Block-sparse FFN | 允许部分 off-diagonal blocks |
| Shared global subspace | 每组保留 local features，同时读写少数 shared dimensions |

### 推荐形式

Block diagonal + low-rank cross-group mixing：

$$
\mathrm{FFN}_{group+mix}(x)=
W_2^{block}\sigma(W_1^{block}x)+
U_2\sigma(U_1x)
$$

其中第一项是 group-specific features，第二项是低秩 global mixing。

也可以写成：

$$
y = W_{block}x + \alpha W_{mix}x,\quad \mathrm{rank}(W_{mix})\ll d
$$

### 为什么 limited mixing 可能更适合可解释性

完全 grouped：模块清楚但性能可能差。  
完全 dense：性能强但 superposition 高。  
limited mixing：保留模块边界，同时允许少量跨模块组合，可能是 interpretability/performance 的折中点。

### LLM / MI 应用

Grouped efficient structures 曾用于 BERT/Transformer 变体，但 **面向 LLM mechanistic interpretability 的 limited-mixing grouped FFN 研究不足**。这是一个非常适合作为论文创新点的 architecture variant。

---

## 5. Hierarchical Grouped FFN

### 是否已有直接论文？

截至 2025 年，尚未形成广泛采用的“Hierarchical Grouped FFN for LLM interpretability”标准架构。相近方向包括：

- hierarchical MoE
- modular networks
- tree-structured neural networks
- hyperbolic / hierarchy-aware representation learning
- depth-wise abstraction in Transformer MLPs

### Research Gap

缺少直接研究：

1. FFN group 是否可对应 concrete / abstract / relational / causal feature levels。
2. 层级分组是否让 SAE features 更少 duplication。
3. hierarchical FFN 是否更容易形成 cross-layer causal circuits。

### 可提出设计

#### 设计 A：Concrete -> Abstract -> Relation

每层 FFN 内部按 group 分为：

- lexical/concrete group
- entity group
- relation group
- abstract/task group

层内 limited mixing：

$$
x_{concrete}\rightarrow x_{entity}\rightarrow x_{relation}\rightarrow x_{abstract}
$$

#### 设计 B：Low-level FFN -> High-level FFN

把 FFN 拆为两级：

$$
h_1=\sigma(W_{low}x),\quad
h_2=\sigma(W_{high}P h_1),\quad
y=W_o[h_1,h_2]
$$

其中 $P$ 是稀疏或低秩投影。

#### 设计 C：Entity / Relation / Causal Subspaces

用辅助 loss 或 orthogonal regularization 约束：

$$
\mathcal{S}_{entity}\perp \mathcal{S}_{relation}\perp \mathcal{S}_{causal}
$$

然后用 SAE 分别解析每个 subspace。

## 6. Gated FFN / GLU Variants

### 代表论文

| Mechanism | Paper | Year | Authors | Link |
|---|---:|---|---|---|
| GLU variants | *GLU Variants Improve Transformer* | 2020 | Shazeer | [arXiv](https://arxiv.org/abs/2002.05202) |
| PaLM | *PaLM: Scaling Language Modeling with Pathways* | 2022 | Chowdhery et al. | [arXiv](https://arxiv.org/abs/2204.02311) |
| LLaMA | *LLaMA: Open and Efficient Foundation Language Models* | 2023 | Touvron et al. | [arXiv](https://arxiv.org/abs/2302.13971) |

### 公式

标准 FFN：

$$
\mathrm{FFN}(x)=W_2\sigma(W_1x)
$$

GLU family：

$$
\mathrm{GLU}(x)=(xW_a)\otimes \sigma(xW_g)
$$

常见变体：

$$
\mathrm{ReGLU}(x)=(xW_a)\otimes \mathrm{ReLU}(xW_g)
$$

$$
\mathrm{GEGLU}(x)=(xW_a)\otimes \mathrm{GELU}(xW_g)
$$

$$
\mathrm{SwiGLU}(x)=(xW_a)\otimes \mathrm{Swish}(xW_g)
$$

### gate 如何改变 FFN

Gate 让 FFN 从“检测后写入”变成“检测 + 条件放大/抑制”：

- $W_a$ 产生 candidate feature。
- $W_g$ 决定 feature 是否通过。
- elementwise product 增强输入条件选择性。

### LLM 应用

SwiGLU/GLU variants 已广泛用于 PaLM、LLaMA、Qwen、Gemma、Mistral/Mixtral 等现代 LLM。它是少数从性能优化进入主流 LLM 的 FFN 变体。

### 是否可能产生更稀疏、更单义激活？

可能。Gate 可以让某些 hidden channels 只在特定上下文激活，增加 activation selectivity。但 gate 不等于显式 sparsity；SwiGLU 通常仍是 dense activation，只是数值选择性增强。需要与 L0/L1 或 SAE 评估结合。

### SAE 结合情况

许多 SAE 工作分析现代 gated-MLP 模型的 activations，例如 Gemma/LLaMA 系列，但很少把 ReLU FFN vs SwiGLU FFN 作为控制变量研究其对 SAE feature quality 的因果影响。

## 7. Mixture of Experts FFN

### 代表论文

| Mechanism | Paper | Year | Authors | Link | Code |
|---|---:|---|---|---|---|
| Sparsely-Gated MoE | *Outrageously Large Neural Networks* | 2017 | Shazeer et al. | [arXiv](https://arxiv.org/abs/1701.06538) | [Tensor2Tensor](https://github.com/tensorflow/tensor2tensor) |
| GShard | *GShard* | 2020 | Lepikhin et al. | [arXiv](https://arxiv.org/abs/2006.16668) | internal/partial |
| Switch Transformer | *Switch Transformers* | 2021 | Fedus et al. | [arXiv](https://arxiv.org/abs/2101.03961) | [google-research/t5x](https://github.com/google-research/t5x) |
| Mixtral | *Mixtral of Experts* | 2024 | Mistral AI | [arXiv](https://arxiv.org/abs/2401.04088) | [mistralai](https://github.com/mistralai) |
| DeepSeekMoE | *DeepSeekMoE* | 2024 | Dai et al. | [arXiv](https://arxiv.org/abs/2401.06066) | [DeepSeek](https://github.com/deepseek-ai) |
| DeepSeek-V2 | DeepSeek-V2 | 2024 | DeepSeek-AI | [arXiv](https://arxiv.org/abs/2405.04434) | [DeepSeek-V2](https://github.com/deepseek-ai/DeepSeek-V2) |
| DeepSeek-V3 | DeepSeek-V3 Technical Report | 2024 | DeepSeek-AI | [arXiv](https://arxiv.org/abs/2412.19437) | [DeepSeek-V3](https://github.com/deepseek-ai/DeepSeek-V3) |

### 核心公式

MoE 用多个 expert FFN 替代单个 FFN：

$$
y=\sum_{e\in \mathrm{TopK}(r(x))} p_e(x) E_e(x)
$$

router：

$$
p(x)=\mathrm{softmax}(W_rx)
$$

Switch Transformer 使用 top-1 routing；GShard/Mixtral 常用 top-2 routing；DeepSeekMoE 使用更细粒度专家与共享专家设计。

### Load balancing loss

传统 MoE 需要负载均衡：

$$
L=L_{LM}+\lambda L_{balance}
$$

DeepSeek-V3 报告采用 auxiliary-loss-free load balancing strategy，减少辅助损失对主任务的干扰。

### Expert specialization

MoE 可以被理解为 **token-level modular FFN**：

- 不同 token routed 到不同 experts。
- expert 可能按语言、领域、语法、实体类型、任务类型分工。
- 但 expert specialization 不一定人类可解释，也可能只是负载/频率模式。

### 与 MI / SAE 的关系

已有少量分析 expert routing 和 specialization 的工作，但与 SAE 的系统结合不足。值得研究：

- 对每个 expert output 训练 SAE。
- 比较 shared expert vs routed expert 的 feature monosemanticity。
- 对 router decision 做 causal intervention。
- 检查 expert 是否对应 SAE feature clusters。

### 诱导潜力

| Property | Potential |
|---|---|
| Monosemanticity | 中到高。token-level sparsity 和专家分工可能减少每个 expert 的 feature burden |
| Hierarchy | 中。若使用 shared + routed + hierarchical MoE 可更强 |
| Causality | 中。router 是明确干预点 |
| Disentanglement | 中到高，但需防止 expert collapse 和 duplicated experts |

## 8. Wider / Deeper FFN

### 代表论文

| Work | Year | Link |
|---|---:|---|
| *One Wide Feedforward is All You Need* | 2023 | [Apple](https://machinelearning.apple.com/research/one-wide-ffn), [arXiv](https://arxiv.org/abs/2309.01826) |

### 核心观察

Transformer FFN 占据大量参数，并承担大量 token-wise transformation。扩大 FFN 宽度通常增加模型容量；加深 FFN 则增加同一 token 内的 feature composition depth。

### 对 feature composition 的影响

- Wider FFN：更多 basis directions，可能缓解 superposition，但也可能增加冗余。
- Deeper FFN：更强 nonlinear composition，可能形成层内层级，但更难解释。
- Shared wide FFN：可能减少层间冗余，但也可能混合不同抽象层级。

### SAE feature quality

假设：

- 宽 FFN 如果降低每个 neuron 的 feature load，可能提高 SAE feature separability。
- 深 FFN 如果形成复合特征，可能提高 semantic abstraction，但 SAE 需要更多层内 hook 点。

### 最新趋势

现代 LLM 多采用较宽 gated FFN 或 MoE FFN；纯粹“更深 FFN”不如 MoE/SwiGLU 流行。研究上可作为控制变量：保持参数量，比较 width vs group vs sparsity。

## 9. Low-Rank / Factorized / Tensorized FFN

### 代表方向

| Direction | Idea |
|---|---|
| Low-rank FFN | $W\approx UV^\top$ |
| Factorized FFN | 分解 up/down projections |
| Tensorized Transformer | 用 tensor train / tensor decomposition 压缩参数 |
| LoRA on FFN | 对 FFN 权重加低秩适配 |
| Parameter-efficient FFN | adapters, bottleneck FFN |

### 数学形式

$$
W_1 \approx A_1B_1,\quad W_2\approx A_2B_2,\quad r\ll d
$$

或 bottleneck：

$$
h=\sigma(W_{up}W_{down}x)
$$

### 表征影响

低秩限制可能诱导低维 subspace：

- 优点：减少冗余，可能提高 subspace interpretability。
- 缺点：容量不足可能迫使更多特征叠加，增加 polysemanticity。

### SAE 结合情况

LoRA/adapter 可解释性已有一些研究，但“low-rank FFN 是否更适合 SAE”缺少系统实验。建议作为次级控制变量。

---

## 10. Sparse FFN / Activation-Sparse FFN

### 代表方向

| Mechanism | Description |
|---|---|
| L1 activation penalty | 对 FFN hidden activation 加 $\lambda\|h\|_1$ |
| k-sparse FFN | 每个 token 只保留 top-k hidden units |
| Hoyer sparsity | scale-invariant sparsity penalty |
| neuron sparsity | 让 neuron activation frequency 更低 |
| group lasso | group-level sparse activation |
| sparse MLP | block / dynamic sparse computation |

### 公式

标准：

$$
h=\sigma(W_1x),\quad y=W_2h
$$

L1 sparse FFN：

$$
L=L_{LM}+\lambda\mathbb{E}_{x}\|h(x)\|_1
$$

Top-k FFN：

$$
h'=\mathrm{TopKMask}(h,k)\odot h
$$

### 与 SAE 的关系

SAE 目标：

$$
L_{SAE}=\|x-\hat{x}\|_2^2+\lambda\|z\|_1
$$

Sparse FFN 直接把类似稀疏压力加到原模型内部，而不是事后分解。因此它可能更直接诱导 monosemanticity。但风险是：

- 过强 sparsity 损害 LM loss。
- 模型可能通过 residual stream 绕过 sparse hidden。
- 稀疏 neuron 不等于单义 feature。

### 研究空白

缺少端到端训练 Transformer 时系统调节 FFN activation sparsity，并用 SAE metrics 评估 feature monosemanticity 的工作。这是强创新点。

---

## 11. Dynamic / Conditional FFN

### 定义

Dynamic FFN 指 FFN 参数、路径、宽度或激活子网络随输入变化。MoE 是最重要的实例，但还有：

- dynamic depth
- conditional computation
- token-dependent adapters
- input-dependent low-rank updates
- early exit / adaptive computation

### 与 MoE 的区别

| Aspect | MoE | Dynamic FFN |
|---|---|---|
| Unit | expert FFN | any conditional path/parameter |
| Routing | usually top-k experts | gates, masks, generated weights |
| Modularity | explicit | variable |
| Interpretability | router/expert inspectable | depends on mechanism |

### 可解释性潜力

上下文相关路径可能形成 contextual feature modules，但也可能让分析复杂化。建议从 MoE 或 top-k sparse FFN 开始，而不是任意 hypernetwork。

---

## 12. Modular FFN

### 背景

Modular neural networks、neural module networks、compositional generalization Transformer 等方向都试图把模型拆成可组合模块。对 LLM 表征而言，模块化意味着：

- 不同 subspace / expert / group 承担不同 feature family。
- 模块间通信可被显式干预。
- circuit localization 更清楚。

### 与 interpretability 的关系

Modularity 并不自动等于 interpretability，但它提供了更好的归因边界：

- module ablation
- module-specific SAE
- router analysis
- feature-to-module assignment

### SAE 结合情况

系统空白：还没有成熟范式把 modular FFN 训练目标、模块结构和 SAE post-hoc evaluation 合并为一个标准实验。

### SAE 通常分析哪里？

- residual stream
- MLP pre-activation / post-activation

- layer output
- MLP input-output mapping via transcoders

### 是否有人专门修改 FFN 来让 SAE 更容易解析？

目前主流工作更多是 **训练 SAE 解析已训练模型**，而不是 **修改 Transformer FFN 让 SAE 更容易解析**。Transcoder 是向 component-level sparse replacement 迈出的一步，但它通常仍是事后拟合原 MLP，而不是从头训练原模型使用 sparse/transcoder-style FFN。

### Research Gap

强空白：端到端训练 Transformer with grouped/sparse/gated/MoE FFN，然后用相同 SAE architecture 和相同 SAE training tokens 比较 monosemanticity、feature duplication、circuit localization。

# Part III. Loss / Objective Variants

## 1. Standard Next-Token Prediction Loss

### 公式

$$
L_{LM}=-\sum_t\log p(x_t|x_{<t})
$$

### 为什么它主要学习统计相关

Next-token loss 奖励预测下一个 token 的概率。它不区分：

- 真因果关系 vs 相关线索。
- 层级概念 vs 平面 co-occurrence。
- 单义 feature vs polysemantic superposed feature。
- 可解释算法 vs black-box shortcut。

### 为什么仍可能隐式学到结构

语言数据中包含大量结构：

- 句法层级。
- 实体关系。
- 因果叙述。
- 程序执行。
- 数学推理。

LM loss 可能通过压缩预测任务隐式学到这些结构，但没有显式要求它们以可分离、可干预、可解释形式存在。

---

## 2. Auxiliary Losses for Representation Shaping

### 类型

| Auxiliary Loss | Signal |
|---|---|
| syntactic supervision | POS, dependency, constituency |
| semantic role labeling | predicate-argument structure |
| entity typing | entity category |
| relation prediction | entity-entity relation |
| concept prediction | human-defined concepts |
| discourse relation | document-level structure |

### 形式

$$
L=L_{LM}+\lambda L_{aux}
$$

例如 entity typing：

$$
L_{entity}=-\sum_i y_i\log \hat{y}_i
$$

### 表征影响

辅助 loss 可以把某些概念线性化、局部化或提前编码到 hidden states。风险是：

- 需要标签。
- 可能过拟合标注体系。
- $\lambda$ 过大损害 LM。
- 可能诱导 probe-friendly representation，而非 causally used representation。

### 控制变量价值

很高。Auxiliary loss 是最容易解释的表征干预之一，适合作为 Loss-only 实验组。

## 3. Contrastive Learning Objectives

### 代表论文

| Work | Year | Authors | Link |
|---|---:|---|---|
| SimCLR | 2020 | Chen et al. | [arXiv](https://arxiv.org/abs/2002.05709) |
| Supervised Contrastive Learning | 2020 | Khosla et al. | [arXiv](https://arxiv.org/abs/2004.11362) |
| Sentence-BERT | 2019 | Reimers & Gurevych | [arXiv](https://arxiv.org/abs/1908.10084) |
| SimCSE | 2021 | Gao et al. | [arXiv](https://arxiv.org/abs/2104.08821) |

### 公式

InfoNCE：

$$
L_i=-\log
\frac{\exp(\mathrm{sim}(z_i,z_i^+)/\tau)}
\sum_{j}\exp(\mathrm{sim}(z_i,z_j)/\tau)}
$$

### 如何塑造 embedding space

Contrastive loss 拉近正样本、推远负样本，使语义类别、句子等价关系、增强不变量更容易线性分离。

### 层级和因果可能性

- 层级：可用 taxonomy-aware positive/negative sampling。
- 因果：可把 cause/effect pairs 设计成有方向的 contrastive pairs，但普通对比学习不自动学习因果。
- 与 LM 结合：多任务训练 $L=L_{LM}+\lambda L_{contrast}$。

### 风险

普通 contrastive loss 可能鼓励全局 embedding separation，但不保证 token-level internal features 单义。

## 4. Hierarchical Losses

### 代表论文

| Work | Year | Link |
|---|---:|---|
| *Poincare Embeddings for Learning Hierarchical Representations* | 2017 | [arXiv](https://arxiv.org/abs/1705.08039) |
| *Hyperbolic Neural Networks* | 2018 | [arXiv](https://arxiv.org/abs/1805.09112) |

### 为什么双曲空间适合层级结构

树结构节点数量随深度指数增长，双曲空间体积也随半径指数增长，因此适合嵌入 taxonomy / hierarchy。

Poincare ball distance：

$$
d_{\mathbb{D}}(u,v)=\mathrm{arcosh}\left(
1+2\frac{\|u-v\|^2}{(1-\|u\|^2)(1-\|v\|^2)}
\right)
$$

### 可用于 Transformer hidden states 吗？

可以作为 regularizer：

1. 将 hidden state 投影到 hyperbolic space。
2. 用 taxonomy distance 约束 entity/concept 表示。
3. 对 residual stream 加 hierarchy-aware contrastive loss。

### 样例 loss

给定概念树距离 $d_T(i,j)$：

$$
L_{hier}=\sum_{i,j}\left(d_{\mathbb{H}}(z_i,z_j)-\alpha d_T(i,j)\right)^2
$$

或层级对比：

$$
L=-\log
\frac{\sum_{p\in P_h(i)}\exp(\mathrm{sim}(z_i,z_p)/\tau_h)}
\sum_{a}\exp(\mathrm{sim}(z_i,z_a)/\tau)}
$$

### 控制变量价值

非常高。它直接对应“abstract-concrete structure”，但需要 taxonomy 或可构造层级标签。

## 5. Causal Representation Learning Objectives

### 代表论文 / 综述

| Work | Year | Link |
|---|---:|---|
| *Invariant Risk Minimization* | 2019 | [arXiv](https://arxiv.org/abs/1907.02893) |
| *Causal Representation Learning: A Review* | 2021 | [arXiv](https://arxiv.org/abs/2102.11107) |
| causal abstraction for MI | 2020s | [JMLR causal abstraction](https://www.jmlr.org/) |

### 什么是 causal representation

Causal representation 不只是能预测标签，而是编码能在干预、环境变化、反事实下保持稳定的因果变量。

### 语言模型中如何训练因果关系

可用目标：

- cause-effect relation prediction
- counterfactual data augmentation
- intervention consistency
- invariant prediction across environments
- temporal/causal direction classification

### IRM 形式

多环境 $e$ 下学习 representation $\Phi$，使同一个 classifier $w$ 在所有环境上最优：

$$
\min_{\Phi,w}\sum_e R^e(w\circ\Phi)
\lambda\sum_e\|\nabla_{w|w=1.0}R^e(w\circ\Phi)\|^2
$$

### 是否需要显式因果标签？

强因果表示通常需要至少一种额外信息：

- 多环境数据。
- 干预数据。
- 反事实 pairs。
- 因果图或弱标签。

只靠 architecture 结构很难保证因果表示。

### 控制变量版本

LM + causal relation prediction：

$$
L=L_{LM}+\lambda L_{cause/effect}
$$

可用人工或合成数据构造 cause/effect pairs，测试 causal direction probing 与 intervention effect。

## 6. Disentanglement Losses

### 代表论文

| Work | Year | Link |
|---|---:|---|
| beta-VAE | 2017 | [OpenReview](https://openreview.net/forum?id=Sy2fzU9gl) |
| DIP-VAE | 2017 | [arXiv](https://arxiv.org/abs/1711.00848) |
| FactorVAE | 2018 | [arXiv](https://arxiv.org/abs/1802.05983) |

### 视觉中怎么做

Disentanglement 目标通常通过限制 latent capacity 或惩罚 total correlation：

$$
L_{\beta VAE}=L_{recon}+\beta D_{KL}(q(z|x)\|p(z))
$$

FactorVAE 惩罚 total correlation：

$$
TC(z)=D_{KL}(q(z)\|\prod_j q(z_j))
$$

### 迁移到 Transformer residual stream

可以对 residual projection $z=P h$ 加：

- covariance penalty
- total correlation proxy
- orthogonality
- group independence

但难点是语言变量本身高度纠缠，完全独立假设可能不合理。

### Orthogonality loss 适合做控制变量吗？

适合。它简单、可微、标签需求低：

$$
L_{orth}=\|Z^\top Z-I\|_F^2
$$

或对 feature covariance：

$$
L_{cov}=\sum_{i\neq j}\mathrm{Cov}(z_i,z_j)^2
$$

## 7. Sparsity Losses

### 类型

| Loss | Formula / Idea |
|---|---|
| L1 activation | $\lambda\|h\|_1$ |
| L0 / hard concrete | penalize number of active units |
| k-sparse | retain top-k activations |
| Hoyer | $\|h\|_1/\|h\|_2$ based sparsity |
| entropy penalty | low entropy over gates |
| group lasso | $\sum_g\|h_g\|_2$ |
| neuron sparsity | penalize activation frequency |

### 与 SAE 的关系

SAE 用 sparse code $z$ 重构 activation $x$。Sparsity loss 直接让原模型 hidden state 或 FFN activation 稀疏：

$$
L=L_{LM}+\lambda\|h_{FFN}\|_1
$$

可能优点：

- 减少 feature superposition。
- 让 neurons/features 更少同时激活。
- 提高 SAE 的 feature recovery。

风险：

- 稀疏激活可能只是降低容量。
- 过强稀疏会损害 perplexity。
- 模型可能转移信息到 attention/residual。

### 与 Top-k attention / Sparse FFN 的区别

| Mechanism | Sparsity Target |
|---|---|
| Top-k attention | token-token routing edges |
| Sparse FFN | hidden neurons / FFN activations |
| Sparsity loss | continuous penalty, can apply anywhere |
| SAE | post-hoc latent code sparsity |

## 8. Orthogonality / Independence Losses

### 代表论文

| Work | Year | Link |
|---|---:|---|
| Barlow Twins | 2021 | [arXiv](https://arxiv.org/abs/2103.03230) |
| VICReg | 2021 | [arXiv](https://arxiv.org/abs/2105.04906) |

### Barlow Twins

目标让两个 views 的 cross-correlation matrix 接近 identity：

$$
L=\sum_i(1-C_{ii})^2+\lambda\sum_{i}\sum_{j\neq i}C_{ij}^2
$$

### VICReg

包括 invariance、variance、covariance 三项：

$$
L=\lambda s(Z,Z')+\mu[v(Z)+v(Z')]+\nu[c(Z)+c(Z')]
$$

### 对 Transformer hidden states 的意义

可以减少 feature redundancy，提升 subspace separability。适合用于：

- residual stream projected features
- FFN group outputs
- SAE decoder directions
- attention head outputs

### 风险

过度 orthogonality 可能惩罚真实相关概念，例如 entity 和 relation、syntax 和 semantics 之间天然相关。

## 9. Bottleneck / Information Bottleneck Objectives

### 代表论文

| Work | Year | Link |
|---|---:|---|
| *Deep Variational Information Bottleneck* | 2016 | [arXiv](https://arxiv.org/abs/1612.00410) |

### 核心思想

Information bottleneck 希望表示 $Z$ 保留预测 $Y$ 的信息，同时压缩输入 $X$：

$$
\min I(X;Z)-\beta I(Z;Y)
$$

Variational form：

$$
L=L_{task}+\beta D_{KL}(q(z|x)\|p(z))
$$

### 如何诱导抽象

Bottleneck 迫使模型丢弃不必要细节，保留预测相关因素。这可能形成更抽象、更稳定的表示。

### 可加位置

- residual stream bottleneck
- FFN hidden bottleneck
- attention output bottleneck
- layer-wise stochastic bottleneck

### 与 SAE 的关系

Bottleneck 可能减少 superposition，但也可能让表示过度压缩、损害 SAE 重构。建议作为 loss-only control。

## 10. Predictive Coding / World Model Objectives

### 代表论文

| Work | Year | Link |
|---|---:|---|
| I-JEPA | 2023 | [arXiv](https://arxiv.org/abs/2301.08243) |
| V-JEPA | 2024 | [Meta AI](https://ai.meta.com/blog/v-jepa-yann-lecun-ai-model-video-joint-embedding-predictive-architecture/) |

### Latent prediction vs next-token prediction

Next-token prediction 预测离散 token：

$$
p(x_t|x_{<t})
$$

Latent prediction 预测未来或被遮蔽部分的 latent representation：

$$
L=\|f_\theta(context)-\mathrm{stopgrad}(g_\phi(target))\|^2
$$

### 是否更可能学习抽象语义？

可能。Latent prediction 不需要逐像素/逐 token 重构细节，可能更关注高层状态。但语言中 token 本身已经是离散语义单位，优势不如视觉中明显。

### 与 Transformer LM 结合

可设计：

- LM + future hidden state prediction
- LM + sentence-level latent prediction
- LM + masked span latent prediction
- LM + world-state variable prediction

适合测试 hierarchy 和 causality，但实现复杂度高于简单 auxiliary losses。

## 11. SAE-Inspired Training Objectives

### 相关方向

| Direction | Description |
|---|---|
| sparse dictionary learning | post-hoc decompose activations |
| integrated SAE loss | train model with sparse reconstruction auxiliary loss |
| transcoders | approximate MLP input-output behavior with sparse features |
| sparse feature circuits | build feature-level causal graphs |
| crosscoders | cross-layer / model-diff sparse features |

### 有没有人把 SAE 直接放进训练目标？

少量探索存在，但主流 SAE 工作仍是 **post-hoc**：先训练或使用 LLM，再在 activations 上训练 SAE。Transcoder/crosscoder 更接近 component replacement or analysis，但通常不是从头训练基础模型时把 SAE 作为主架构约束。

### 可提出目标

对某层 residual $h_l$：

$$
z_l=\mathrm{TopK}(\mathrm{ReLU}(W_eh_l+b_e))
$$

$$
\hat{h}_l=W_dz_l+b_d
$$

联合训练：

$$
L=L_{LM}
\lambda_{rec}\|h_l-\hat{h}_l\|_2^2
\lambda_{sparse}\|z_l\|_0
\lambda_{orth}\|W_dW_d^\top-I\|_F^2
$$

### 风险

- 训练成本高。
- SAE loss 可能与 LM objective 冲突。
- 模型可能学会让 SAE 容易重构但不更可解释。
- 需要 rigorous evaluation，不能只看 L0/reconstruction。

### Research Gap

“SAE as post-hoc evaluation tool” 已成熟；“SAE-inspired objective as representation shaping during LM pretraining” 仍是高价值空白。

# Part V. Recommended Controlled Experiments

## Core Question

哪类机制最能诱导 Transformer 学到更单义、更层级、更因果、更适合 SAE 解析的表示？

## General Controls

所有实验必须固定：

- architecture scale：layers, $d_{model}$, heads, context length 尽量匹配。
- parameter count：通过调整 FFN width / group width / expert count 匹配 active parameters。
- dataset：同一 pretraining corpus。
- tokenizer：同一 tokenizer。
- optimizer：AdamW / schedule / batch size / gradient clipping 一致。
- training tokens：完全一致。
- random seeds：至少 3 个 seeds。
- evaluation checkpoints：same token counts。
- SAE architecture：same expansion factor, activation function, sparsity target。
- SAE training tokens：同一 activation dataset。
- SAE hook point：residual stream + MLP output + attention output 至少三类。

## 实验矩阵 A：Attention-only

| Group | Change | Control Notes |
|---|---|---|
| A0 | Baseline dense attention | standard causal MHA |
| A1 | Top-k attention | same heads; $k=32/64$; causal mask first |
| A2 | Entmax attention | replace softmax with entmax-1.5 |
| A3 | Threshold attention | adaptive percentile threshold |
| A4 | NSA-style dynamic hierarchical sparse | compressed global + fine token selection, small-scale version |

假设：

- Top-k/threshold 会提高 attention path sparsity 和 circuit localization。
- Entmax 会在不引入 hard discontinuity 的情况下提高 attention support interpretability。
- NSA-style 可能更有利于 hierarchy metrics。

## 实验矩阵 B：FFN-only

| Group | Change | Control Notes |
|---|---|---|
| F0 | Standard FFN | ReLU/GELU baseline |
| F1 | Grouped FFN | block-diagonal up/down projections |
| F2 | Grouped FFN with limited mixing | block + low-rank mixing |
| F3 | Gated FFN / SwiGLU | parameter-matched hidden dim |
| F4 | Sparse FFN | L1 or Top-k hidden activation |
| F5 | MoE FFN | top-1/top-2 small expert count, active params matched |

假设：

- Grouped + limited mixing 最可能提升 modular feature formation。
- Sparse FFN 最可能提升 SAE monosemanticity，但需监控 LM loss。
- MoE 可能提升 expert-level modularity，但 feature duplication 风险高。
- SwiGLU 可能提升 selectivity，但未必提升可解释性。

## 实验矩阵 C：Loss-only

| Group | Objective | Control Notes |
|---|---|---|
| L0 | LM loss only | baseline |
| L1 | LM + L1 activation sparsity | apply to FFN hidden or residual projection |
| L2 | LM + orthogonality loss | covariance penalty on projected hidden states |
| L3 | LM + hierarchy contrastive loss | taxonomy/concept hierarchy labels |
| L4 | LM + causal relation prediction loss | cause/effect pair labels |
| L5 | LM + bottleneck loss | stochastic or deterministic bottleneck |

假设：

- L1/orthogonality 对 monosemanticity 最直接。
- hierarchy contrastive 对层级 probing 最直接。
- causal relation loss 对 causal direction probing 和 intervention 最直接。
- bottleneck 可能提升 abstraction，但 LM 性能风险较高。

## Recommended Minimal First Paper Design

第一篇论文不宜同时改所有东西。建议：

1. 小型 causal LM：6-12 layers, 100M-300M 参数。
2. 三条主线各选 3 个机制：
   - Attention：dense, Top-k, entmax。
   - FFN：standard, grouped+mix, sparse FFN。
   - Loss：LM, LM+L1, LM+orthogonal。
3. 训练同 token 数。
4. 对每个 checkpoint 训练同规格 SAE。
5. 用 SAE + probes + circuit metrics 统一评估。

# Part VI. Evaluation Metrics

## 1. Language Modeling Metrics

| Metric | Meaning |
|---|---|
| validation loss | primary LM quality |
| perplexity | $\exp(L_{val})$ |
| downstream accuracy | optional, e.g. BLiMP, SuperGLUE subset, syntactic/semantic tasks |
| calibration | expected calibration error |
| long-context performance | if attention variant targets long context |

## 2. SAE Metrics

### Fidelity / Sparsity

| Metric | Formula / Meaning |
|---|---|
| reconstruction loss | $\|x-\hat{x}\|_2^2$ |
| loss recovered | LM loss recovered when replacing activation by SAE reconstruction |
| KL divergence | output distribution shift after SAE replacement |
| L0 sparsity | average active features per token |
| L1 sparsity | average $\|z\|_1$ |
| dead feature rate | fraction of features never or rarely activated |
| activation frequency | per-feature activation distribution |

### Interpretability / Monosemanticity

| Metric | Meaning |
|---|---|
| auto-interpretability score | LLM-generated explanations evaluated on held-out activations |
| precision/recall of feature explanation | feature activates exactly when explanation predicts |
| feature polysemanticity | number/diversity of unrelated concepts per feature |
| feature splitting | one concept split across many features |
| feature duplication | multiple features with same explanation/subspace |
| ablation effect sparsity | whether ablating one feature causes localized behavioral change |
| causal intervention effect | activation patch / feature steering effect on target behavior |

### Suggested SAE Protocol

Train SAEs on:

- residual stream after each block
- MLP output
- attention output
- MoE expert output if applicable
- group-specific FFN output if applicable

Use same:

- expansion factor, e.g. 16x or 32x
- sparsity target, e.g. TopK SAE L0 = 32 or JumpReLU matched L0
- training tokens
- optimizer and steps

## 3. Representation Metrics

| Metric | Purpose |
|---|---|
| linear probing for hierarchy | test whether concept level/taxonomy is linearly recoverable |
| relation probing | subject-object/relation classification |
| causal direction probing | classify cause -> effect vs effect -> cause |
| clustering purity | do known concept classes cluster |
| mutual information | estimate feature-label dependence |
| subspace overlap | compare entity/relation/causal subspaces |
| CKA similarity | compare layer representations across variants |
| representation anisotropy | detect collapsed/dominant directions |
| feature orthogonality | cosine/covariance among learned features |
| intrinsic dimension | estimate effective dimensionality |

## 4. Circuit Metrics

| Metric | Attention | FFN | SAE Feature Circuit |
|---|---|---|---|
| path sparsity | support size / entropy of attention | n/a | number of edges in feature graph |
| head specialization | head-task mutual information | n/a | feature-head association |
| FFN neuron specialization | n/a | activation selectivity | neuron-feature alignment |
| circuit localization | few heads/layers sufficient? | few neurons/groups/experts? | few SAE features sufficient? |
| causal faithfulness | activation patching effect | MLP patch/ablation | feature ablation/steering |

## 5. Composite Scores

Define a normalized research score:

$$
S_{mono}=w_1 I_{score}-w_2 Poly-w_3 Dup-w_4 Dead
$$

$$
S_{hier}=w_1 Probe_{hier}+w_2 Cluster_{taxonomy}-w_3 SubspaceOverlap
$$

$$
S_{causal}=w_1 Probe_{direction}+w_2 InterventionEffect-w_3 SpuriousSensitivity
$$

Report tradeoff:

$$
\Delta S / \Delta L_{LM}
$$

即每损失一点 LM 性能换来多少 interpretability gain。

# Part VII. Final Research Gap Summary

## 1. 哪些机制已经被充分研究？

相对充分：

- Standard attention / Transformer circuits。
- Attention head specialization and pruning。
- FFN as key-value memory。
- Gated FFN for performance。
- MoE for scaling and efficiency。
- Post-hoc SAE for monosemantic feature discovery。

但“充分”主要指性能或事后解释，不是指 architecture causally induces monosemanticity。

## 2. 哪些机制只是为了效率提出，但可能被重新用于可解释性？

最值得重新解释：

- Top-k attention：content-based sparse routing。
- Entmax/sparsemax attention：differentiable sparse routing。
- Native Sparse Attention：dynamic hierarchical sparse long-context routing。
- Grouped FFN：block-structured modular feature formation。
- MoE FFN：token-level conditional modularity。
- Low-rank FFN：subspace bottleneck。
- MQA/GQA/MLA：shared KV / latent KV 对 head specialization 的影响。

## 3. 哪些机制已经和 SAE 结合？

已经较明确结合：

- residual stream SAE
- MLP activation SAE
- attention/MLP output SAE
- TopK SAE
- JumpReLU SAE
- gated SAE
- transcoders for MLP circuits
- sparse feature circuits
- crosscoders / cross-layer feature analysis

这些大多是 **post-hoc analysis**，不是训练原模型时的 architecture/loss intervention。

## 4. 哪些机制还没有和 SAE 结合？

缺少系统研究：

- Top-k attention + SAE feature quality。
- Entmax attention + SAE。
- Threshold attention + causal path analysis。
- NSA-style attention + hierarchy/SAE。
- Grouped FFN + SAE。
- Grouped FFN with limited mixing + SAE。
- Hierarchical grouped FFN + SAE。
- Sparse FFN trained end-to-end + SAE。
- MoE expert specialization + SAE feature circuits。
- Orthogonality/sparsity/hierarchy/causal loss + post-hoc SAE comparison。

## 5. 哪些机制最值得作为论文创新点？

### Innovation Point 1：Top-k Attention for Interpretable Sparse Routing

Hypothesis：

> Content-based hard sparse routing reduces attention path superposition and improves feature circuit localization.

实验：

- Dense vs Top-k vs Entmax。
- Same model size/tokens。
- Evaluate attention path sparsity, SAE monosemanticity, feature-level causal tracing。

### Innovation Point 2：Grouped FFN for Modular Feature Formation

Hypothesis：

> Block-structured FFN with limited cross-group mixing induces modular feature subspaces that are easier for SAE to decompose.

实验：

- Standard FFN vs grouped FFN vs grouped+low-rank mixing。
- Group-specific SAE and residual SAE。
- Measure feature purity, duplication, subspace overlap。

### Innovation Point 3：Sparse / Orthogonal Loss for Monosemanticity

Hypothesis：

> Direct activation sparsity and decorrelation losses reduce feature superposition before SAE training.

实验：

- LM only vs LM+L1 vs LM+orthogonal vs LM+L1+orthogonal。
- Evaluate SAE L0, dead features, interpretability, LM loss tradeoff。

### Innovation Point 4：Hierarchical Loss for Abstract-Concrete Structure

Hypothesis：

> Hierarchy-aware contrastive loss makes residual subspaces encode concept abstraction levels more linearly and improves cross-layer feature organization.

实验：

- Build synthetic taxonomy or use WordNet/entity ontology。
- Evaluate hyperbolic distance, hierarchy probing, SAE feature level assignment。

### Innovation Point 5：Causal Loss for Cause-Effect Representation

Hypothesis：

> Causal relation prediction and counterfactual consistency induce features whose interventions have directionally meaningful effects.

实验：

- Cause/effect classification auxiliary objective。
- Counterfactual pairs。
- Probe causal direction and perform feature steering/ablation。

## Recommended Research Route

### 阶段 1：Monosemanticity First

先比较 Attention-only / FFN-only / Loss-only 对 SAE monosemanticity 的影响。

优先组合：

- Attention：dense vs Top-k vs entmax。
- FFN：standard vs grouped+mix vs sparse FFN。
- Loss：LM vs LM+L1 vs LM+orthogonal。

输出：

- SAE reconstruction/sparsity frontier。
- feature interpretability score。
- polysemanticity/duplication/dead feature metrics。
- LM loss tradeoff。

### 阶段 2：Hierarchical Representation

对阶段 1 最有效机制进一步测试层级表示。

实验：

- 加 hierarchy contrastive loss。
- 使用 taxonomy/probe。
- 比较 feature activation 是否从 concrete 到 abstract 随层变化。
- 检查 grouped FFN 是否自然对应层级 subspaces。

### 阶段 3：Causal Representation

最后测试 causal representation。

实验：

- cause/effect auxiliary loss。
- counterfactual data。
- feature intervention。
- sparse feature circuits。
- 比较哪些机制产生最局部、最方向性、最可干预的 causal features。

## Final Thesis

目前 Transformer 可解释性研究已经证明：SAE 可以从已训练 LLM 中提取大量更单义的 sparse features。但更关键的下一步不是只继续扩大 SAE，而是反过来问：

> 如果我们改变 attention routing、FFN modularity、training objective，能否让模型一开始就学习更适合 SAE 解析的内部表示？

最有希望的路线是：

1. 用 **Top-k / Entmax Attention** 约束信息路由。
2. 用 **Grouped FFN with Limited Mixing** 约束 feature formation。
3. 用 **Sparse + Orthogonal Loss** 约束 feature geometry。
4. 用 **Hierarchical / Causal Auxiliary Loss** 约束语义结构。
5. 用 **SAE / Transcoder / Sparse Feature Circuits** 作为统一评价工具。

这形成一个清晰的研究地图：从 architecture-induced sparsity，到 loss-induced geometry，再到 SAE-measured monosemanticity、hierarchy、causality。
